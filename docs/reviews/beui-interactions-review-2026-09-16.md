# Be UI 交互分支审查与页面走查

范围：`codex/beui-interactions`，从 `f9cf0845` 后的交互提交及当前未提交改动。未审查开发运行目录、依赖链接和用户主工作区的其他改动。

## 已发现并修复

1. **P2：审核按钮样式丢失。** Bala 图片审核操作替换为 ApprovalCard 后删除了 `.bala-card-actions` 容器，原按钮尺寸、边框和选中态规则不再匹配。恢复操作容器，保留卡片布局。
2. **P2：审核保存标记未隔离批次，且读取状态有副作用。** 天猫审核保存快照只有决策内容，两个批次内容相同时可能继承旧“已保存”标记。现在同时比较批次 ID；将 `prepareEditableBatch` 从供 computed 调用的取值函数移到显式保存入口，避免状态展示时写回表单。

修复后，在本轮检查范围内未发现其他需要阻断本地合并的明确问题；这不是所有供应商或完整业务流程的验收结论。
