## 验收标准

每款必须同时满足以下条件：

1. `tmt.png` 为 800×800 RGBA；原图不足画布时居中贴透明底，不拉伸。
2. 每色 `jdt.<款色名色号>.png` 为 800×800 RGBA；原图不足画布时居中贴透明底，不拉伸。
3. 每色 `wpt30.<款色名色号>.png` 保持原图尺寸和透明通道，文件严格小于 600 KB。
4. `tmq.jpg` 为 800×800，来自鞋盒/吊牌标签图，红框必须包含当前完整 12 位款号，不得只验证“存在红像素”。
5. 每色 `tms.jpg` 使用该色 `tmz5` 同一源图并输出白底 JPG。
6. 图色文件夹和渠道图命名必须使用鞋盒标签识别出的“款色名称+5 位色号”；模型未可靠识别时失败关闭，不沿用姿势模型臆测名称。
7. `tmz1..tmz5`、`o`、每色 `yq1..yq3` 的数量和姿势均匹配 Excel 指定品类的模板。特别要求：非雪地 `tmz4` 为完整单鞋后侧/侧后；`yq3` 为无遮挡、完整外侧面；`yx` 仅允许完整鞋与功能吊牌/功能卡同框。
8. `wpz5` 与 `wpz6` 不得是同一张或近重复图片；`wpz6` 必须是鞋盒标签图。
9. 自动验证、语义证据和逐图 contact sheet 可视复核三层均通过；单纯 `issues=[]` 不构成交付证据。

## 架构

### 1. 结构化候选语义

所有姿势策略都要求视觉模型逐候选返回结构化事实，而不是直接填槽位：

```json
{
  "candidate_id": "I01",
  "filename": "GUDO7377.jpg",
  "asset_type": "shoe",
  "shoe_count": "single",
  "pose": "tmz4",
  "background": "gray",
  "complete": true,
  "side": "rear",
  "outsole_visible": false,
  "feature_card": false,
  "matched_slots": ["tmz4", "wpz4"],
  "confidence": 0.92
}
```

候选事实必须引用真实候选编号和文件名。几何特征只用于排除局部图、白灰底错误和近重复，不再作为最终姿势裁判。

### 2. 双模型独立共识

同一候选集合至少获得两个不同模型路由的独立结果。每个结果先单独经过 SlotRule 生成槽位，再按槽位投票：

- 两个独立模型选择同一文件，或选择同一无损拷贝族，才允许自动锁定。
- 模型分歧、候选缺失、硬规则冲突、低置信度或只有一个有效模型结果时，槽位留空并令当前款验证失败。
- fallback 的职责是补足独立票数，不再是“第一个成功即停止”。

### 3. 确定性硬门禁

`core/shenhui_shoe_rules.py` 负责可测试的语义门禁：

- 主图候选必须是完整鞋图，且不能含功能卡遮挡。
- 非雪地 `tmz4` 必须为 `rear/side_rear/heel` 语义，不接受普通外侧面或斜前方。
- `yq3` 必须 `complete=true`、`side=outer`、`feature_card=false`。
- `yx` 必须 `complete=true`、`feature_card=true`，普通鞋图和局部卡片均拒绝。
- `wpz6` 必须是 `shoe_box/label`；`wpz5` 必须是完整单鞋。

### 4. 鞋盒标签、命名与 tmq

鞋盒 OCR 结果必须包含：正确 12 位款号、正确 5 位色号、非空款色名称、标签框和款号文字框。模型框通过本地 OCR/文字行几何复核；若无法定位完整款号，`tmq` 不生成且当前款失败。

生成 `tmq` 后，验证器再次 OCR 成图，并检查识别出的完整款号文字框被红框包围。文件夹名必须等于经鞋盒 OCR 验证后的款色名与色号。

### 5. 证据传递与验证

打包报告为每个语义槽位保存候选事实、模型路由和共识状态。验证器逐项检查：

- 文件存在性、数量、尺寸、模式、透明度、体积、白底亮度；
- 模板语义硬门禁与共识票数；
- 文件夹命名来源；
- `tmq` 完整款号与红框重叠；
- 主图和关键 `wpz/yq` 的近重复冲突。

每款另生成 contact sheet 供最终逐图检查。自动验证失败或可视检查失败时，保留当前款证据，修复后只重跑当前款。

## 错误处理

- 模型配置、超时或 JSON 结构失败：尝试下一个模型；不足两票则当前款失败。
- 鞋盒 OCR 不可靠：尝试独立模型和本地 OCR；仍不可靠则当前款失败，不用猜测名称或款号框。
- 槽位没有合格候选：留空并明确报错，不为凑数量选择错误图片。
- 运行失败：不复制到最终目录，不进入下一款。

## 测试与交付边界

先为 `tmz4/yq3/yx/双模型共识/款色名/tmq` 写失败测试，再实施最小修复。完成后依次运行聚焦单测、鞋包完整测试、八款真实串行重跑、逐图 contact sheet 检查及 `git diff --check`。
