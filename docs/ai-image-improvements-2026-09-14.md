# 生图供应商、工作台与天猫测图改动总结

## 供应商与模型

- 图片模型设置改为 1XM、沃卡、森马网关三个固定供应商，加自定义供应商。各供应商分组编辑地址、密钥和模型；自定义支持 OpenAI Images、Gemini 原生、1XM 异步协议。
- 沃卡、森马接入 GPT Image 2、Nano Banana 2、Nano Banana Pro 的文生图与参考图编辑。GPT Image 2.5 实测未开通，从内置选项隐藏；旧模型名称增加 1XM 标识，历史无前缀模型继续走 1XM。
- 覆盖 AI 生图、AI 视频工作流改图、巴拉换脸换背景脚本、买家秀、天猫测图及云端审批派发/直接生成路径。保存配置后共享模型目录即时更新，直接切页可识别和调用，无需刷新或重启。
- 设置页不提供测试生图。缺少 Key 时，开始生成替换为红色“去配置”，显示醒目错误文案并跳转图片模型设置。

## 同步调用、多图和重试

- 同步供应商共享并发上限 3，延长请求与桌面 IPC 等待时间。明确限流或临时忙碌最多尝试 3 次，退避 1、2 秒；鉴权、额度和未开通模型不自动重试。
- 超时、断连、502/504 等受理未知情况保存 UNKNOWN_SUBMIT_RESULT，避免自动重复付费提交；买家秀不再叠加外层重试。
- 保留批次成功图片，显示部分成功与逐项失败原因，记录实际提交次数和非敏感连接版本，保持恢复/重试时供应商身份。

## 输入与工作台交互

- 提交后保留主图、参考图和 Prompt；每轮保存完整输入快照，结果可沿用对应轮次参数并追加生成。
- 只区分主图、参考图和顺序，传给模型时明确角色；移除同款多角度/多款合成模式及推断商品分组，处理要求由用户 Prompt 定义。
- 主图最多 6 张、总输入最多 10 张、单张最多 20 MiB；预览与提交统一校验，超限明确报错，不静默截断。
- 文件选择、外部拖入及剪贴板导入共用校验与缓存，主图/参考图分别记忆目录。移除粘贴按钮，保留快捷键粘贴。
- 拖入时提示松手添加、当前数量、上限和剩余容量，导入后反馈新增/重复/失败；排序和上传事件隔离。
- 主图/参考图改为紧凑缩略图网格，自动换行，保留删除、拖拽插入线及方向键排序。悬停显示文件名；点击仅打开大图，支持关闭按钮、背景点击及 Escape，无编辑控件。

## 天猫测图

- 款号模板和 Prompt 模板末尾各预留自定义1～自定义10，贯通 Excel/CSV 导入、本地编辑保存、任务传参、云端元数据/版本/导出与两条匹配链路。
- 款号表已填字段与模板同名字段逐项匹配，多个条件同时满足；规范空白，忽略空字段，全部留空沿用原品类/性别逻辑。显式条件可跨工作表匹配，无命中时报告条件，不回退到无关 Prompt；支持 {{自定义1}}～{{自定义10}} 替换。
- 显式匹配不追加与创意拍/合拍冲突的默认构图禁令，交由业务 Prompt 定义。
- 换脸仅出现在天猫测图审批生成结果，复用现有巴拉模特库、换脸提示词和供应商执行能力；按年龄/性别选模特，可加补充要求。
- 原结果不覆盖，每次新增一张待审批结果，记录来源图与模特；沿用源图供应商参数，生成完成读取最新审批数据再追加，保留期间已保存的审批决定。

## 验证与交付边界

- 提交前复跑：114 项 Python、84 项本地 JavaScript、19 项云端测试通过；云端 TypeScript、桌面 Vite 构建、主进程/预加载语法及暂存区空白检查通过。

- 本次仅本地 Git 提交；未推送、打包发布或部署云端。云端直接生成仍需在部署环境独立配置供应商凭据，本机密钥不写入源码或提交。
