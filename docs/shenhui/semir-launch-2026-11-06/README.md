## 实现

版本 0.2.0，总计 4 个业务任务。参考了 SCM 运营助手、森马云盘 SHEIN 完整目录下载和深绘后端整理模式。

- 云盘：已观察 `/fengcloud/1/account/mount`、`/fengcloud/1/file/ls`、`/fengcloud/2/file/info`。指定批次根目录逐款匹配，保留目录树及全部原始文件；不使用跨季度搜索兜底，不按同名文件去重，不猜渠道图片槽位。支持同一次运行多个静物/模特/补图来源。
- SCM：实地核实洗唛页和三方检测页 Vue `sfLayoutMainTable` 及其 `handleRequest`。通过页面自身请求封装查询，认证留在页面内。直接无认证 fetch 返回 401，未将其当作无数据；实现没有导出或重放页面令牌。
- 洗唛查询字段 `ADVANCED_SEARCH[P_MAT_CODE]`；报告字段 `ADVANCED_SEARCH[PRD_CODE]`。校验实际分页起点和筛选值，按记录 ID 检测重复页，检测总数变化及空页提前结束。网络失败后旧表格不视为成功。
- 分页每页 50，单款最多 200 页；超过上限报不完整。保留页面其它筛选及平台原生固定过滤，不能声称取得所有状态的报告。
- 原件分款/类型/来源或记录 ID 存放；导出 ZIP、Excel 和 JSON 清单。唯一任务目录避免覆盖，路径穿越与冲突拒绝入包；下载的 PDF 和图片校验类型，保留 SHA256。原图、PDF不做转换或改写。
- 后端接入 `core.semir_launch_packaging.package_materials`，只对新增三个任务生效。已有工作区的其它改动保持原样。
