# 抓虾交互改进计划

分支：`codex/beui-interactions`，基于 `f9cf0845`，使用独立 worktree。

## 设计约束

- 借鉴 beUI 的交互模式，用 Vue 实现；不引入 React/Motion/Tailwind 依赖。
- 复用抓虾 `--bg/--bg2/--bg3/--text/--text2/--border/--orange` 主题变量、6–12px 圆角和现有按钮层级。
- 动效以 opacity/transform 为主，150–220ms；支持 reduced motion。商品图 contain，状态由真实异步结果驱动。
- 保留所有业务限制、审核权限与未知提交结果保护，不以动画模拟业务进度。

## 实施与验收

1. **File Upload**：主图、参考图和批量导入逐文件队列；立即占位、处理、成功、失败、重试、移除。保持数量/大小校验与任务归属。
2. **Agent Activity**：任务执行步骤与工作流阶段；当前步骤展开，完成折叠，允许手动查看历史详情。
3. **Infinite Masonry**：移植可视区域渲染/预加载思想，素材和生成历史仍采用规则网格；检查大量图片的 DOM 数量、滚动、选择保留。
4. **Approval Card**：AI 图片决定与天猫确认区域；内容和操作集中展示，保存后保留摘要，失败不显示成功。
5. **Animated Toast Stack**：全局同 ID 通知更新，用于下载、复制和配置保存；成功自动收起、错误保留，支持打开文件夹。
6. **StatefulButton**：生成、配置保存和下载操作；固定空间显示提交/成功/失败，阻止重复提交。
7. **Combobox**：模型、提示词库与模板选择；搜索、分组、方向键/Enter/Escape，兼容移除的选择项。
8. **Command Palette**：全局快捷入口、脚本任务和最近访问；Ctrl/Cmd+K、搜索、键盘导航、关闭后焦点恢复。

## 验证

- 相关单元测试、Vue 编译构建、git diff 检查。
- 从本分支启动隔离数据目录的 Electron 源码客户端，验证页面和 IPC。
- 用本地固定数据验证长列表和成功/错误交互；不触发付费生成、外部审批或商品提交。
- 保留开发客户端供用户复查；本轮不推送、不发布。

- 参考 https://beui.dev/components/agents/image-generation 的固定画布、点阵等待和结果渐显，自行用 Vue/CSS 实现，复用抓虾主题。
- 删除旧海浪/虾图等待动画和循环文案计时器。排队与生成状态由实际队列驱动；收到结果后等待图片加载再渐显，不模拟供应商细化进度。

- 支持 reduced motion；离屏暂停点阵动画；保留失败处理与 UNKNOWN_SUBMIT_RESULT 禁止直接重试规则。

- 源码 Electron 实测新增、设为默认、编辑留空 Key 保存、两步移除及默认模型恢复；临时供应商已清理，未调用真实文本模型。
- 移除主图/参考图标题旁的重复上传按钮；保留上传区并支持有图后继续添加，达到容量上限或导入中禁用。
- 失败卡片突出“一键重试”，复用原有队列快照重试、重复点击锁和轮询；提交结果未知仍禁止直接重试。实际客户端点击本地失败样例验证 IPC 与缺失 Key 反馈，成功重试由模拟供应商测试覆盖，未执行付费生成。
