## 三个真实失败

1. 沃卡 Nano Banana 2，视频工作流换姿势：约 20 秒返回但没有图片，提示 `供应商响应未包含图片：{}`；本次不自动重提。证据：`video-pose_swap--woka--gemini-3.1-flash-image-preview.json`。
2. 沃卡 Nano Banana Pro，视频工作流换脸：约 62 秒被远端断开。工作台保存未知回执并阻止直接重试，未重提。证据：`video-face_swap--woka--gemini-3-pro-image-preview.json`。
3. 沃卡 GPT Image 2，天猫审批结果换脸：约 66 秒被远端断开，API 返回 HTTP 400 和断连错误。本次未重提，原图未覆盖；是否已受理/计费未知。证据：`tmall-face-swap--woka--gpt-image-2.json`。

还发现一个需要后续修复的错误提示差异：天猫换脸只返回通用 HTTP 400/断连文字，没有像工作台那样向界面返回结构化 UNKNOWN_SUBMIT_RESULT。本次测试主动停止重提，不等于已经证明天猫换脸界面具备相同的持久化防重提保护。

## 实测方法与边界

- 所有表内组合均使用实际沃卡/森马网络请求和已授权本机配置；没有模拟生成结果，没有用生成成功占位图冒充供应商输出。
- 工作台、批量、重试、天猫审批通过实际 FastAPI 路由的本地 HTTP 请求；其余调用生产业务执行函数：`_apply_bala_ai_face_background_generate`、`_generate_buyer_show_row`、`_apply_tmall_ai_image_generation`。巴拉换脸/换背景脚本与 AI 视频工作流、森马买家秀脚本与买家秀工作流复用这些执行链路。
- 这属于接口/业务执行层的逐入口真实回归，不声称逐个页面的所有点击都完成了端到端验收。源码客户端另做两次原生 UI 提交并回读真实结果，见 `ui-readback.json`。
- 业务素材使用现有巴拉 AI 模特库、测试用蓝色 T 恤图形及本轮实际生成结果。天猫审批换脸源图来自本轮工作台编辑成功图。上游登录、云盘爬取、实际商品发布/天猫投放不在生图验证范围，未触发。
- 手动重试先用仅限该请求的无效测试凭据取得真实鉴权拒绝，再从正式重试 API 读取隔离配置中的有效 Key 成功执行；未修改用户供应商配置。该测试验证永久拒绝不自动重试、手动恢复后调用成功，不声称真实流量触发过 429/503。此前故障注入对 429/503 的验证仍应单独看待。
- 首次视频换脸测试缺少隔离适配器注册，尚未发供应商请求；补齐安装/扫描后进行了真实请求。首次买家秀6组已生成图片但缺少测试云盘来源元数据，卡在用量记录；补齐元数据复用已有结果落图，不再次付费生成。旧记录保存在 `precondition-failures/`，最终结果中的 `reused_paid_generation` 标明复用。
- 独立数据目录 `/tmp/crawshrimp-entry-live-regression-20260914`，没有覆写原任务/配置。原生 UI 增加了一个独立回归任务，UID 已记录；结果仍保留供查看。
- 云端相关本地执行函数调用在用户排除该范围前已经结束，原始记录保留但不进入上表、分母或结论；没有线上部署、派发或回传验收，没有外部发信。
