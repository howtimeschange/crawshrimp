# 森马上新助手

当前清单包含 5 个业务任务。

| 任务 | 输入 | 产出 |
| --- | --- | --- |
| 静物图云盘分包与吊牌洗唛核验 | 上架明细 Excel、云盘目标目录 | 按款色整理的图包，原表末尾追加四个核验列 |
| PLM 尺码表批量导出 | 款号、所选/全部尺码 | 当前修订版宽表、长表和错误表，业务阶段待确认 |
| 批次图包下载整理 | 款号、带素材类型的批次目录 | 原目录素材、分款 ZIP、来源/颜色/哈希清单 |
| SCM 洗唛吊牌下载 | 款号、是否仅完成、页面其它筛选 | 分款色原件、中英文成分、采购单/记录来源及缺件清单 |
| SCM 三方检测报告下载 | 款号、页面其它筛选 | 全分页报告附件、检测项目/机构/颜色与来源明细 |

图包目录每行一个，格式为：

```text
静物|森马bu-森马商品//3-商品上新/3-01季度上新/2026年/26Q3/静物图/女/8P（07.30）/
模特|挂载点//实际模特批次目录/
补图|挂载点//经确认的补图目录/
```

每个来源独立保留，只采集所填目录下对应款号/款色文件夹；不跨批次寻找兜底文件。不按相机文件名猜正面、背面或渠道槽位。明确的款色目录和中文色名加五位编码目录可提取色号；有冲突时留空待核。

SCM 使用已登录页面自己的 Vue 表格查询方法，读取全部分页；保留当前品牌、季节、样品阶段等筛选。三方检测页面本身还有已完成、合格/实测等配置筛选，采集范围以该页面为准，不代表该款所有阶段和所有判定的报告。保留多条记录和全部附件，不静默选择最新或第一条；报告的适用性和有效期仍需业务核对。

新任务输出目录：

```text
资料包名称_时间/
  原件/款号/资料类型/...原目录或记录ID.../文件
  款号.zip
  资料明细.xlsx
  资料清单.json
```

原件不改写。重复运行创建独立目录；路径冲突不覆盖。清单保留 SHA256、字节数、来源路径、适用颜色、下载状态与异常。PDF/图片格式校验失败不入包。包状态 `complete` 仅表示本次采集项下载整理完成，不代表达到上新发布条件；无记录、缺件、失败均记为 `partial`。

## 静物图云盘分包

可从任务界面下载空白上架明细模板，上传本次要处理的 `.xlsx`。季度、批次和上市日期从表格读取。来源目录支持多条，可逐行输入「库名//目录/子目录」或云盘网页地址。留空时搜索上架年份及前一年的森马视觉静物目录。目标目录可配置，本次测试默认指向 `森马bu-森马商品//3-商品上新/3-01季度上新/2026年/26Q3/静物图/测试`。

默认新开森马云盘页面，并执行「云盘复制并改名」。表格可填写「第8批」或「8P」，新建的批次目录使用「8P」，图包写入「批次/男或女/款号」。季度用于匹配来源和结果表回填。整款来源包含表格未列出的款色时，只复制表格指定款色。支持来源为整款目录或独立款色目录，中性归男装。来源同等匹配或已有目标内容冲突时，结果标为待核，目标同名文件不会被覆盖。

脚本先通过云盘服务端复制整批图包，按表中色名和五位色号命名，并逐个比对目标目录和文件哈希。整批整理结束后，内置 PP-LCNetV2 3.3 按吊牌、洗唛、普通图和供应商样卡四类排序。浏览器生成内存裁图，本机 PP-OCRv4 读印刷号，必要时用 Tesseract 复读。普通图高分可暂缓，命名标签图始终参与检查。即使两类标签有匹配款号，也会扫完其他优先候选，检查异款实物标签。证据不齐、读图失败或存在冲突时回扫暂缓图片。

正式吊牌以零售价或有效商品条码等零售信息为依据。只读到款号、通用标准或合格证信息时，吊牌类型留待复核。明确的供应商样品卡和表单不计作吊牌。OCR 保留 A/B 等款号后缀，读到同主款的不同后缀记为款号不一致，仅读到主款号则记为后缀待复核。源表副本追加「缺吊牌」「缺洗唛」「款号是否一致」「备注」。

OCR 并发根据本机逻辑核数和物理内存自动选择，最多 12 个 Worker。Windows 使用系统内存接口，缺少系统读数时使用浏览器读数。单图 OCR 超时会回收对应 Worker，并在当前任务自动重试一次。云盘登录失效时，任务保留已整理清单和已完成的核验结果，同一标签页恢复登录后自动继续剩余款色。

实现入口、模型输入约定和 A/B 对照数据见 [Listingify 开发交接](../../docs/handoffs/2026-11-25-semir-still-image-listingify.md)。
