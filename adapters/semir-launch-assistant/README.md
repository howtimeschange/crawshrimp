# 森马上新助手

当前版本 0.2.0，共 4 个业务任务。

| 任务 | 输入 | 产出 |
| --- | --- | --- |
| 森马 PLM 尺码表批量导出 | 款号、所选/全部尺码 | 当前修订版宽表、长表和错误表，业务阶段待确认 |
| 森马批次图包下载整理 | 款号、带素材类型的批次目录 | 原目录素材、分款 ZIP、来源/颜色/哈希清单 |
| 森马 SCM 洗唛吊牌下载 | 款号、是否仅完成、页面其它筛选 | 分款色原件、中英文成分、采购单/记录来源及缺件清单 |
| 森马 SCM 三方检测报告下载 | 款号、页面其它筛选 | 全分页报告附件、检测项目/机构/颜色与来源明细 |

图包目录每行一个，格式为：

```text
静物|森马bu-森马商品//3-商品上新/3-01季度上新/2026年/26Q3/静物图/女/8P（07.30）/
模特|挂载点//实际模特批次目录/
补图|挂载点//经确认的补图目录/
```

每个来源独立保留，只采集所填目录下对应款号/款色文件夹；不跨批次寻找兜底文件。不按相机文件名猜正面、背面或渠道槽位。明确的款色目录和中文色名加五位编码目录可提取色号；有冲突时留空待核。

SCM 使用已登录页面自己的 Vue 表格查询方法，读取全部分页；保留当前品牌、季节、样品阶段等筛选。三方检测页面本身还有已完成、合格/实测等配置筛选，采集范围以该页面为准，不代表该款所有阶段和所有判定的报告。保留多条记录和全部附件，不静默选择最新或第一条；报告的适用性和有效期仍需业务核对。

新任务输出目录：

```text
资料包名称_时间/
  原件/款号/资料类型/...原目录或记录ID.../文件
  款号.zip
  资料明细.xlsx
  资料清单.json
```

原件不改写。重复运行创建独立目录；路径冲突不覆盖。清单保留 SHA256、字节数、来源路径、适用颜色、下载状态与异常。PDF/图片格式校验失败不入包。包状态 `complete` 仅表示本次采集项下载整理完成，不代表达到上新发布条件；无记录、缺件、失败均记为 `partial`。

## 运行要求

新增 3 个任务需要本仓库 `core.semir_launch_packaging` 和 `core.api_server` 后处理接入，不能仅把适配器安装到未更新的旧客户端后端。2026-11-06 已在独立源码后端安装、执行并回读实际产物；正式打包 Harness 尚未更新。

## SOP 范围与待办

- MDM 企业码：用户已有接口，明确不实现抓取。
- 产品制单需求：按用户最新说明，可能仅需尺码表，暂由现有森马 PLM 导出任务覆盖，不新增制单原件下载。2026-11-09 周一确认是否仅需尺码表，以及当前修订版是否满足所需业务阶段；尚未作最终业务确认。
- 上架主表、文案、下单尺码范围：SOP 是运营/计划提供的 Excel 与协作流程，尚无固定自动取数入口，列为后续本地批次输入/对账能力，不虚构抓取系统。女装以独立女装表为主，中性按男装目录。
- 渠道规范库与必填逻辑：属于建档校验规则，不是素材采集脚本；本包不写入深绘或 Listingify。
