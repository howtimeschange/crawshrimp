# 上新运营助手抓虾适配包

本适配包包含两套并列的分图流程和一个 PLM 尺码表下载任务，共五个任务：

1. **生成分图审核表**：从本地目录或森马云盘路径扫描批次、匹配上市计划表、推导目标路径，输出固定 13 列 Excel。
2. **审核后上传云盘**：重新读取审核表和原来源，在明确授权后执行本地文件/文件夹上传或云盘服务器端复制；保留源款式文件夹内的相对目录结构，不会处理“需复核”行。
3. **静物核表分图**：粘贴一批17位款色号，按前12位在首级“摄影”库搜索候选文件夹；只有包含精确“12位款号-后5位色号.jpg”的文件夹才通过，多文件夹命中时选择图片最多的一个。
4. **静物核表上传**：只读取核表中的款色号、对应JPG和已选摄影源路径，复核后把摄影文件夹内容按原相对目录结构复制到目标目录，不需要原源批次公共根目录。
5. **尺码表PDF下载**：在 Centric PLM 中按款号批量搜索，按“大货→订货→试销单→内评→初版”选择最优尺码表，将 PDF 下载到指定文件夹并生成结果 Excel。

## 使用方式

1. 在抓虾中导入本 ZIP。
2. 运行“1. 生成分图审核表”，先选择“本地上传”或“云盘上传”，完整填写映射并选择“已确认，可以开始”。云盘模式会自动打开森马云盘；如尚未登录，请在打开的页面完成登录，程序会自动继续。
4. 打开输出 Excel 审核；需阻止某行上传时，把状态改为“需复核”。
5. 运行“2. 审核后上传云盘”，选择与第一步相同的来源、审核表和原路径，再选择“审核通过，允许上传”。

核表流程则运行“3. 静物核表分图”，审核输出表后直接运行“4. 静物核表上传”。第4步只上传审核表并确认授权。

尺码表流程运行“5. 尺码表PDF下载”，使用已登录的 PLM 页面，粘贴款号并选择保存文件夹即可。

## 输入约定

- 本地模式选择包含一个或多个批次的公共根目录；云盘模式填写 `挂载点//相对路径`。两种模式都优先识别文件夹名中的唯一 17 位款色号，找不到时再识别唯一 12 位款号。
- 本地和云盘模式都扫描 JPG/JPEG/PNG/WEBP/PSD。云盘模式通过已登录的森马云盘标签页递归读取并在服务器端复制，不会把源文件下载到电脑。
- 核表版输入必须是17位款色号。前12位作为款号搜索首级“摄影”库，后5位作为色号；候选文件夹名称前12位必须与款号完全一致。
- 每个候选文件夹都会递归查找精确的 `12位款号-5位色号.jpg`（扩展名大小写不敏感，带 `-1` 等额外后缀的不算）。没有该JPG的文件夹不进入上传来源。
- 多个候选文件夹都包含对应JPG时，只选择有效图片和PSD数量最多的一个，并在审核表、结果表备注“多个文件夹包含该款色，已选图片多的上传”；最高数量并列时标记“需复核”，不自动上传。
- 核表审核表中的“摄影源路径”是第4步的来源依据。第4步会重新读取所选路径，核对17位款色号、对应JPG和文件数量。
- 任务1和任务3都有“是否保留源文件命名”：默认不保留，沿用“款号 + 自定义内容 + 日期”；选择保留后，任务1使用源款式文件夹完整名称，任务3使用最终选中的摄影文件夹完整名称。自定义内容和日期都留空时，最终名称就是对应的完整源文件夹名称。
- 任务3默认选择“保留源文件命名”，使用“平拍原图”作为自定义路径项，并以“静物回图”作为最终文件夹自定义内容；任务1仍默认“不保留源文件命名”和“模拍原图 / AI新回图”。
- 常规上市批次会统一为 `nP` 目录；`326以上`、`0p`、`0P`、`特殊批`等特殊非空值会原样作为批次目录。
- 计划表同时存在“正季上市/上市批次”和“上市规划/上市批次”时，优先使用正季上市批次；正季上市批次为空时，再使用上市规划批次。
- 程序会扫描计划表前20行定位包含“大货款号”的真实表头，并识别其上一行的上市批次分组。
- 款色号列会从“大货款色号、款色号、款色编码、SKU编码、商品编码”中识别。
- 必需字段为“上市批次、产品线”；当产品线为“婴幼童”时再要求“年龄段”。同名列由抓虾读取后可能显示为 `_2`、`_3` 后缀，程序会统一检查。
- Sheet 映射格式为每行 `Sheet名称=云盘目录`，只查询列出的 Sheet。

## 安全规则

- 未确认配置时不生成审核表；未确认上传授权时不上传。
- 两张计划表都命中时采用计划表 1，并写入备注。
- 无法唯一选定 Sheet、记录或必需字段时标记“需复核”，不推导虚假路径。
- 正常首次上传每款只提交一次，默认等待 300 秒；等待期间只观察云盘数量，超时仍不完整时标记“需复核”，不在同次运行中补传。
- 重新运行发现同名目标文件夹缺图时，先观察目录数量；数量每次变化都会重新计时，稳定满 1 分钟后只补传按文件名确认缺少的图片。
- 若缺图补传时不同款色目录存在同名图片，会把该名称对应的本地图片整组补传，并把结果标记为“需复核”。
- 同款异色只有目标路径一致时才合并处理；本地模式不创建 staging，云盘模式调用 `/fengcloud/1/file/copy` 在服务器端复制。
- 任务2和任务4都会保留款式文件夹下的子文件夹结构：本地来源使用“上传文件夹”，云盘来源直接复制顶层子文件夹，不会把内部图片和PSD拍平到目标根层。
- 云盘复制前后递归按相对路径、filehash、文件大小和文件名核验；目标结构完整时重复运行会跳过，已有同名子文件夹但内部不完整时标记“需复核”，不自动覆盖或拆散目录。
- 核表版不会合并同一款色的多个摄影文件夹；只上传其中图片数量最多的一个。同一12位款号输入多个不同色号时，各款色选中的来源可合并复制到同一款号目标目录。
- 同一款号只要有一个款色处于“需复核”或缺少源图片，整款都不会上传或复制，避免先建立不完整文件夹后无法补色。

## 已知边界

- 抓虾当前的目录扫描器最多返回 10,000 个受支持媒体文件；超过时任务会在客户端显示截断提示，应拆分批次运行。
- 生成审核表的云盘模式会在抓虾受管 Chrome 中自动打开森马云盘并等待登录；登录成功后自动继续读取源路径。本地模式仍在独立空白页运行，不访问森马登录接口。
- 目标目录创建仍使用当前森马云盘的 Element UI 页面结构。若云盘改版导致找不到“新建文件夹”，结果表会明确失败，不会报告虚假完成。
- 抓虾通用 Excel 导出暂不支持根据扫描结果动态修改文件名，因此审核表文件名为 `分图汇总审核表-YYYYMMDD.xlsx`；实际批次数会写入每行来源信息和运行记录。
