# 上新运营助手抓虾适配包

本适配包包含两套并列的分图流程、一个 PLM 尺码表下载任务和一个 SCM 下载任务，共六个任务：

1. **生成分图审核表**：从本地目录或森马云盘路径扫描批次、匹配上市计划表、推导目标路径，输出固定 15 列 Excel。
2. **审核后上传云盘**：重新读取审核表和原来源，在明确授权后执行本地文件/文件夹上传或云盘服务器端复制；上传前会在“巴拉营运BU-商品”全库筛查“模拍原图”业务路径下的同款目录，安全复用唯一旧目录并在核验后改名。
3. **静物核表分图**：粘贴一批17位款色号，按前12位在首级“摄影”库搜索候选文件夹；只有包含精确“12位款号-后5位色号.jpg”的文件夹才通过，多文件夹命中时选择图片最多的一个。
4. **静物核表上传**：只读取核表中的款色号、对应JPG和已选摄影源路径，复核后把摄影文件夹内容按原相对目录结构复制到目标目录，不需要原源批次公共根目录；复制前会在“巴拉营运BU-商品”全库筛查“平拍原图”业务路径下的同款目录，安全复用唯一旧目录并在核验后改名。
5. **尺码表PDF下载**：在 Centric PLM 中按款号批量搜索，按“大货→订货→试销单→内评→初版”选择最优尺码表，将 PDF 下载到指定文件夹并生成结果 Excel。
6. **SCM洗唛电子吊牌下载**：在 SCM“洗唛批复判定”中逐款查询，只取第一组至少包含一个有效文件的记录；洗唛和电子吊牌均支持 JPG/JPEG、PNG、PDF，分别保存到指定文件夹并生成结果 Excel。

## 使用方式

1. 在抓虾中导入本 ZIP。
2. 运行“1. 生成分图审核表”，先选择“本地上传”或“云盘上传”，完整填写映射并选择“已确认，可以开始”。云盘模式会自动打开森马云盘；如尚未登录，请在打开的页面完成登录，程序会自动继续。
3. 打开输出 Excel 审核；需阻止某行上传时，把状态改为“需复核”。
4. 运行“2. 审核后上传云盘”，选择与第一步相同的来源、审核表和原路径，再选择“审核通过，允许上传”。

核表流程则运行“3. 静物核表分图”，审核输出表后直接运行“4. 静物核表上传”。第4步只上传审核表并确认授权。

尺码表流程运行“5. 尺码表PDF下载”，使用已登录的 PLM 页面，粘贴款号并选择保存文件夹即可。

SCM 流程运行“6. SCM洗唛电子吊牌下载”。先在抓虾专用浏览器登录 SCM，再批量粘贴款号并分别选择洗唛、电子吊牌保存文件夹。程序一次处理一款，只采用第一组至少包含一个有效文件的记录，不会跨记录拼接两个文件。

洗唛和电子吊牌都按源格式命名：JPG/JPEG 统一保存为 `具体款号 洗唛.jpg` 或 `具体款号 电子吊牌.jpg`；PNG 保存为 `.png`；PDF 保存为 `.pdf`。

## 输入约定

- 本地模式选择包含一个或多个批次的公共根目录；云盘模式填写 `挂载点//相对路径`。两种模式都优先识别文件夹名中的唯一 17 位款色号，找不到时再识别唯一 12 位款号。
- 本地和云盘模式都扫描 JPG/JPEG/PNG/WEBP/PSD。云盘模式通过已登录的森马云盘标签页递归读取并在服务器端复制，不会把源文件下载到电脑。
- 核表版输入必须是17位款色号。前12位作为款号搜索首级“摄影”库，后5位作为色号；候选文件夹名称前12位必须与款号完全一致。
- 核表版会按最多40个不同款号一批读取摄影库并自动合并结果，支持一次处理数百个款色号，避免单次跨标签页查询超时。
- 每个候选文件夹都会递归查找精确的 `12位款号-5位色号.jpg`（扩展名大小写不敏感，带 `-1` 等额外后缀的不算）。没有该JPG的文件夹不进入上传来源。
- 多个候选文件夹都包含对应JPG时，只选择有效图片和PSD数量最多的一个，并在审核表、结果表备注“多个文件夹包含该款色，已选图片多的上传”；最高数量并列时标记“需复核”，不自动上传。
- 核表审核表中的“摄影源路径”是第4步的来源依据。第4步会重新读取所选路径，核对17位款色号、对应JPG和文件数量。
- 任务1和任务3都有“是否保留源文件命名”：默认不保留，沿用“款号 + 自定义内容 + 日期”；选择保留后，任务1使用源款式文件夹完整名称，任务3使用最终选中的摄影文件夹完整名称。自定义内容和日期都留空时，最终名称就是对应的完整源文件夹名称。
- 任务3默认选择“保留源文件命名”，使用“平拍原图”作为自定义路径项；“最终文件夹自定义内容”默认为空，按需手动填写。任务1仍默认“不保留源文件命名”和“模拍原图 / AI新回图”。
- 常规上市批次会统一为 `nP` 目录；`326以上`、`0p`、`0P`、`特殊批`等特殊非空值会原样作为批次目录。
- 计划表同时存在“正季上市/上市批次”和“上市规划/上市批次”时，优先使用正季上市批次；正季上市批次为空时，再使用上市规划批次。
- 程序会扫描计划表前20行定位包含“大货款号”的真实表头，并识别其上一行的上市批次分组。
- 任务1会按12位款号汇总最终命中 Sheet 内全部款色的“导购”，写到审核表“款号”右侧，例如 `4款“1-棉服”；1款“1-AI-棉服”`。计数按唯一17位款色号去重；缺列、空值或冲突项不计入汇总并写入备注，行状态仍为“待审核”，不影响后续上传。
- 任务2结果表固定为12列，顺序为：日期、源文件夹、款号、产品线、款色号、批次、导购、本地图片数、云盘文件数、上传状态、云盘目标路径、备注。“日期”固定为本次任务开始时的运行日期，使用不补零的 `月.日` 格式（如 `9.1`）；同一次运行的所有结果行保持一致。“源文件夹 / 产品线 / 批次 / 导购”从审核表原样带入；同款多行合并时去重后用分号连接，不重复累加导购的款色数量。旧审核表缺列或空值保持空白，不改变上传判定。任务4结果表保持原结构。
- 任务1在审核表末尾追加“产品线”，保存上市计划表中已匹配的产品线原值（例如“婴幼童”不会被目标目录的“婴童/幼童”替代）。需重新生成审核表或补填该列，任务2才会显示这项信息。
- 款色号列会从“大货款色号、款色号、款色编码、SKU编码、商品编码”中识别。
- 17位款色号必须在计划表中保存为文本格式。若以Excel数值格式保存，末位可能在保存时已经失真；程序会拒绝继续匹配并提示改为文本格式，不会猜测原值。
- 必需字段为“上市批次、产品线”；当产品线为“婴幼童”时再要求“年龄段”。同名列由抓虾读取后可能显示为 `_2`、`_3` 后缀，程序会统一检查。
- Sheet 映射格式为每行 `Sheet名称=云盘目录`。使用两张计划表时可把两张表的映射合并填写；程序会按每张计划表实际存在的 Sheet 分别取交集，不再要求两张表拥有完全相同的 Sheet。映射中的 Sheet 若两张表都不存在，或某张已选择的计划表没有任何映射项，会明确报错，避免静默漏查。

## 安全规则

- 未确认配置时不生成审核表；未确认上传授权时不上传。
- 两张计划表都命中时采用计划表 1，并写入备注。
- 无法唯一选定 Sheet、记录或必需字段时标记“需复核”，不推导虚假路径。
- 任务2本地上传前会分批读取源图片并计算完整 SHA-1 内容指纹（与森马云盘 filehash 一致）和文件大小；每批最多4个文件、按4MiB分片读取，不把图片内容放入跨阶段共享数据。运行期间请勿修改、移动或删除源文件。
- 上传完成必须逐张匹配本次源图片的内容指纹和大小；只同名、只数量达到或超过源数量都不能判成功。默认等待300秒，超时后仅对当前批已识别的缺图自动补传一次，仍缺失则“需复核”并列出文件名，不执行旧目录改名。
- 重新运行发现同名目标文件夹缺图时，先观察目录数量及缺失名单；发生变化会重新计时，稳定满1分钟后只补传内容未匹配的图片。无法取得可验证指纹时标记“需复核”，不猜测已上传。
- 全库筛查唯一命中历史旧同款文件夹，或目标父路径接口确认最终名称已存在时，程序会使用已核验路径直接进入父目录；缺图时至少连续读取 3 次，并确认云盘文件数与缺失名单稳定约 5 秒，上传前再核对一次，只提交仍缺少的文件。
- 同名但内容不同的旧图不会被当作本次源图；上传时保留两者，不覆盖旧图。支持云盘产生的 `1-AI(2).jpg` / `1-AI (2).jpg` 名称，按内容一对一核验，不用一张云盘图片充当多个源文件；相同内容已存在时不重复上传。
- 同款异色只有目标路径一致时才合并处理；本地模式不创建 staging，云盘模式调用 `/fengcloud/1/file/copy` 在服务器端复制。
- 任务2和任务4都会保留款式文件夹下的子文件夹结构：本地来源使用“上传文件夹”，云盘来源直接复制顶层子文件夹，不会把内部图片和PSD拍平到目标根层；任务2每完成一款都会清空该款的结构上传计划，避免大批量时带入下一款。
- 任务2会按12位款号搜索“巴拉营运BU-商品”全库，只接受父路径含独立“模拍原图”目录段、且文件夹名称前12位与款号完全相等的目录；17位款色号开头的文件夹不会误判成同款目录。
- 任务2在推导目标父目录内只发现一个旧同款目录时，会把本次缺少的文件补入旧目录；本地来源须逐张通过完整内容指纹和文件大小核验（有子文件夹时同时核对相对路径），云盘来源沿用原云盘复制校验。核验通过后，先再次确认最终名称不存在，再单击选中旧目录并发送 F2 重命名，不依赖右键菜单。名称按回图类型处理：本次为“AI新回图”或“导购回图”，且旧名称已含同一类型时，只更新该类型后紧跟的日期，其他文字和日期不变；例如本次“导购回图9.4”把“款号 AI新回图8.20-已选8.28 导购回图9.3”更新为“款号 AI新回图8.20-已选8.28 导购回图9.4”。旧名称没有本次类型时，完整保留旧名并追加本次款号之后的内容，不重复款号；相同内容和日期已存在则不再追加或改名。其他自定义命名内容仅追加、不猜测替换其日期。同一类型重复出现、本次目标含多种回图类型或同类型日期无法识别时标记“需复核”，不擅自改写。发现同款位于其他业务父路径、同父路径存在多个旧目录、最终名称与旧名称同时存在，或准备改名时最终名称被新建时，不做不可逆合并并在结果表标记“需复核”。
- 任务4采用同一套目录安全规则，但全库筛查只接受父路径含独立“平拍原图”目录段的同款目录。唯一旧目录会保留其中已有文件和子文件夹，只复制本次摄影源中尚未匹配的完整结构；本次源文件全部按相对路径、filehash 和大小核验后才发送 F2 改为审核表中的最终名称。若同款出现在其他平拍原图父路径、同父路径存在多个旧目录、最终名称与旧名称并存，均标记“需复核”；最终名称与旧名称并存时只复用最终名称，旧目录不动。
- 任务4逐款全库筛查时，单页请求最多等待10秒、整个款号搜索最多20秒且最多读取8页，并会识别搜索接口重复返回同一页的异常循环；异常时自动重试2次，仍失败则只将该款标记“需复核”，明确不复制、不重命名并继续下一款，避免大批量任务被一个异常搜索拖死。
- 云盘复制前后递归按相对路径、filehash、文件大小和文件名核验；目标结构完整时重复运行会跳过，已有同名子文件夹但内部不完整时标记“需复核”，不自动覆盖或拆散目录。
- 核表版不会合并同一款色的多个摄影文件夹；只上传其中图片数量最多的一个。同一12位款号输入多个不同色号时，各款色选中的来源可合并复制到同一款号目标目录。
- 同一款号只要有一个款色处于“需复核”或缺少源图片，整款都不会上传或复制，避免先建立不完整文件夹后无法补色。

- 任务4同款任一颜色标为“需复核”，或来源读取、对应JPG、数量、目标路径等校验失败时，整款不复制、不重命名；其他款号正常继续。
- 任务2云盘来源和任务4都要求有效的完整 SHA-1 指纹与文件大小一致，并核对相对路径与名称；不再仅凭同名同大小判断成功。源文件缺少有效指纹时不提交复制；目标缺少指纹或内容不一致时不能报告核验成功或改名。
- 两个上传任务读取目录时支持没有 total/count 的分页响应，满500项会继续读取；识别重复页、提前空页，每个目录最多40页。云盘读取单请求最多等待10秒，列目录在20秒预算耗尽后不再发起后续请求；全库搜索最多8页、总预算20秒。异常时保留需复核结果，不把已读取的部分列表当作完整结果。
- 任务2沿用 v1.4.19 的改名交互：滚动定位并检查点击遮挡，确认选中后将焦点移到当前旧目录再发送 F2；仅填写值与本款旧名称一致的唯一可编辑输入框，先等待输入框再有限重试。失败行输出改名前的目录路径及具体原因。使用现有抓虾脚本接口的页面键盘事件，不需要安装宿主补丁；若云盘选中标记发生变化会停止改名并标记需复核，需实机确认。

- 本地目录选择器和脚本的云盘递归扫描都以 10,000 个受支持媒体文件为安全上限；超过时会明确报错，应拆分批次运行。云盘上限是脚本为避免内存、CDP传输和超时风险主动设置的安全阀。
- 生成审核表的云盘模式会在抓虾受管 Chrome 中自动打开森马云盘并等待登录；登录成功后自动继续读取源路径，等待超过10分钟会提示重新运行。本地模式仍在独立空白页运行，不访问森马登录接口。
- 目标目录创建仍使用当前森马云盘的 Element UI 页面结构。若云盘改版导致找不到“新建文件夹”，结果表会明确失败，不会报告虚假完成。
- 抓虾通用 Excel 导出暂不支持根据扫描结果动态修改文件名，因此审核表文件名为 `分图汇总审核表-YYYYMMDD.xlsx`；实际批次数会写入每行来源信息和运行记录。
