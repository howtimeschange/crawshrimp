# v2.5.12 · 轻供鞋品素材识别与规范命名

发布日期：2026-10-16

## 深绘吊牌/洗唛/平铺图下载

- 支持轻供鞋品 SKU 目录，白底目录作为兜底，优先保留最高分辨率组；不会将 31、32、1200-4 等图片编号推断成业务色码。
- UUID 命名的电子合格证进入受限 OCR 候选，通过标签字段结构验证后才保留，不把所有 UUID 图片都当作吊牌。
- 已确认的鞋品标签输出为“完整款号_吊牌_01.png/jpg”，款色参考图输出为“完整款号_平铺图_01.jpg”等，完整保留 2084261412A7 这类合法字母款号。
- Excel、CSV、JSON 素材清单同步输出文件名和本地路径，保留原文件名、云盘路径、素材类型、分类依据；区分目录归属与标签货号核验，不擅自建立供应商货号映射或构造成分字段。
- 新增本地素材重打包工具，基于已核验清单另建输出目录，不重复下载或压缩。深绘上新助手适配包更新至 0.3.2。

## Excel 导入与桌面更新

- 修复 Excel 模板尾部无标题列影响列解析、导致有效 ID 丢失的问题。
- 应用内更新使用兼容 R2 的单段 Range 请求；下载停滞时超时退出，支持取消及重试清理，后台检查不再重置正在进行的下载。
- 下载进度未知时显示准备状态，并记录更新进度及错误日志。

## 验证与边界

- 本地命名/素材回归共 65 项测试通过；12 个输入款号实际获取 11 款、35 张图片（24 张参考图、11 张电子合格证），2084261400U6 未匹配到素材，没有独立洗唛图。
- 规范命名重打包后 35 张图的 SHA-256 与原包一致。
- Listingify 对合法字母款号的解析修复由 Listingify 单独处理，端到端导入效果仍需联合验证。
- 各平台构建、正式 Release 与更新源发布状态以本次 GitHub Actions 为准；未宣称已完成 Windows 安装或跨版本自动更新验收。
- README 保留 v2.5.12、v2.5.11、v2.5.10 最近三个版本说明；历史说明继续保存在 release-notes 目录。
