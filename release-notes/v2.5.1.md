# 抓虾 Desktop v2.5.1

发布日期：2026-08-25

`v2.5.1` 是 `v2.5.0` 之后的补丁发布，发布本地领先的桌面更新确认、Bala AI 视频素材质感控制、深绘鞋品图包识别和 Kimi K3 模型配置改进。

版本等级：`PATCH`。本次变更不新增一级产品模块，主要增强已上线桌面更新、AI 视频素材、深绘鞋品图包和多模型配置链路的可控性与稳定性。

## 桌面更新确认体验

- 应用内更新下载完成后新增更新说明确认弹窗，展示目标版本、安装动作和 changelog，再由用户确认是否立即重启安装。
- 主进程、preload 与 renderer 补齐更新说明传递链路，前端可以读取 release note 并展示给用户。
- 更新安装协调器补强延后安装、重复触发和退出安装状态处理，减少下载完成后提示不清或安装动作被重复触发的风险。
- GitHub Actions 桌面构建流程同步补强更新资产和发布说明相关校验，保证正式 tag 构建继续刷新更新 bridge 资产。

## Bala AI 视频素材与换脸质量

- AI 视频工作流的换脸/改图质量控制按模型能力展示可选档位，避免所有模型共用不合适的质量参数。
- 后端图片服务与 API 会记录质量选项和生成证据，便于复核当前图片是按哪个模型与质量档位生成。
- Bala AI 视频助手打包测试覆盖质量选项和生成证据字段，降低适配器 manifest 与前后端参数不一致的风险。
- 历史 AI 视频素材不再自动勾选归档目录里的 AI 产物，默认选择只保留当前流程中更可信的素材，减少旧图误入新批次。

## 深绘鞋品图包识别

- 新增鞋品槽位规则文件，并在深绘鞋品图包流程中使用更明确的主图、角度图、鞋型姿势和缺失素材识别规则。
- `shenhui_shoe_packaging` 重构鞋品识别与打包逻辑，复杂鞋型和多图槽位的失败原因更清晰，方便批量结果复核。
- 新增云盘 rerun 与结果 validator 工具，支持对真实批次输出做结构化复核，不再只靠人工逐图检查。
- Python 回归测试扩大到鞋品槽位、角度图选择、失败隔离和 LLM 网关模型路由，覆盖深绘鞋品链路的主要风险点。

## Kimi K3 多模型入口

- LLM 网关、前端设置和 Bala AI 视频助手 manifest 补齐 `kimi-k3` 模型选项。
- Bala 视频文案、深绘识别等使用统一 LLM 配置的入口可以直接选择 Kimi K3，和 DeepSeek、Gemini、GPT Image 系列保持一致。
