# 抓虾 Desktop v2.4.0

发布日期：2026-07-29

`v2.4.0` 是 `v2.3.1` 之后的功能级发布，包含本地领先 GitHub 的 3 个提交：TEMU 洗水唛自动化、Crawshrimp 1XM Cloudflare Proxy，以及 1XM 图片模型默认代理链路。

## TEMU 洗水唛自动化

- TEMU 适配器新增「后台-洗水唛制作并下载官方 PDF」，读取洗唛需求 Excel 后按 SKC 去重选择代表 SKU，并生成 TEMU 页面 API 所需的洗水唛制作参数。
- 默认 dry-run 不保存；只有显式开启「允许调用 TEMU 保存接口」后才会提交 TEMU 保存接口，并在回读“已制作”后下载官方 PDF。
- 新增「后台-洗水唛官方 PDF 批量下载」，可按洗唛需求 Excel 限定范围，也可扫描店铺内全部已制作且可导出的洗水唛。
- PDF 下载只走 TEMU 官方导出入口，并校验本地文件以 `%PDF-` 开头；失败时输出诊断 JSON，不生成截图恢复稿。

## 浏览器下载与执行底座

- `core/js_runner.py` 支持更稳的浏览器下载接管，适配 TEMU 官方导出弹窗、新标签和页面 API 串联场景。
- `runtime_downloads`、`browser_executor` 和 `web_operator` 补齐下载等待、文件检测、任务日志和失败诊断能力，减少长流程中“点击了但没有证据”的情况。
- 增加 TEMU manifest、洗水唛创建、官方 PDF 下载、JS runner 和下载执行器回归测试，覆盖 dry-run、授权保存、PDF-only 导出和下载异常路径。

## 1XM 图片代理

- 新增 `cloud/one-xm-proxy` Cloudflare Worker，用于在本地直连 `https://api.1xm.ai/v1` 超时时代理 1XM 图片任务创建、轮询与图片结果下载。
- 代理会重写小 JSON 响应中的 `poll_url`，并把 `img.1xm.ai` 结果地址转为 Worker 图片代理入口，让抓虾后续轮询和下载保持在同一代理链路。
- 本地 1XM 图片客户端、设置页默认值和旧配置迁移统一改为 `https://one-xm-proxy.crawshrimp.com/v1`；用户仍可在设置里覆盖为自有 Worker 或原始 1XM 地址。
- Worker README 补充 pass-through auth、代理 token 与 Worker 托管 1XM key 三种部署方式，并配套代理测试。
