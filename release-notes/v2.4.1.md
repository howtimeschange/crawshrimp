# 抓虾 Desktop v2.4.1

发布日期：2026-07-29

`v2.4.1` 是 `v2.4.0` 之后的补丁发布，包含本地领先 GitHub 的 3 个提交：AI 视频工作流改图体验优化、同步大图修改边界，以及深绘鞋品上传包整理的 OCR 打标和命名规则修复。

## AI 视频工作流

- 优化改图步骤的素材选择、任务参数和状态回写，减少审核大图、当前素材池和实际改图任务之间的边界混淆。
- 同步大图修改时保留明确的交互状态和可追踪结果，让运营在审核大图里看到的修改与后续视频素材保持一致。
- 巴拉 AI 视频助手补齐 manifest、素材选择抽屉、后端打包和 UI 工作流测试，覆盖授权素材读取、任务参数构造和异常路径。

## 深绘鞋品上传包整理

- 新增项目级 `tesseract.js` OCR 依赖和 `core/ocr_service.py`，从鞋品整理开始使用新的项目级 OCR 架构，同时保留原有天猫 OCR 实现。
- 鞋盒标签 `tmq.jpg` 打标先识别标签里的款号文本位置，再按文本框绘制红框，适配不同款号图片里标签位置不一致的情况。
- 深绘鞋品图包规则同步本次真实验收反馈：默认主图姿势 1，只有主推色输出 `o.jpg` 和 `yk*`，细节图按实际张数保留到 `yk5`，唯品会后两张输出 `wpz (15)` 与 `wpz (16)`。
- 多模型接入边界补齐 OpenAI / Anthropic 兼容请求头和多模态调用处理，默认姿势识别模型切换为验收效果更稳的模型配置。
