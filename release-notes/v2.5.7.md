# v2.5.7 多供应商生图、鞋品专属模型与 Windows ARM 支持

发布日期：2026-09-16

## AI 图片与视频

- 生图工作台、买家秀及天猫测图接入沃卡、森马等供应商，保留带供应商标识的模型选项，完善参考图输入与结果展示。
- 天猫换脸提交状态持久化，避免回执未知时重复提交；通用提示词模板可参与匹配，无匹配时明确反馈失败。
- 视频提示词模型新增 DeepSeek V4.1 Flash 与 GPT-6 Astra，保留旧 Vision 别名兼容。

## 深绘鞋品图包

- 内置巴拉鞋品专属识别模型、离线 OCR 与条码识别依赖，完善标签优先、双模板选图和语义复核流程。
- 支持按模板整理图包、完整结果审核与导出，改善流式识别超时及异常恢复。

## 桌面性能

- 限制媒体处理并发，合并频繁的工作区持久化，减少大批素材场景下的交互阻塞。

## Windows ARM 安装包

- 新增 `crawshrimp-v2.5.7-win-arm64.exe`，同时保留 Windows x64、macOS Apple Silicon 和 Intel 安装包。
- ARM 包的 Electron 桌面端原生运行；内置 Python、OCR 和鞋品推理依赖仍为 x64，通过 Windows 11 ARM 的 x64 转译运行。此版本不代表完整后端原生 ARM 移植。
- Windows 更新元数据包含两种架构，更新器按当前应用架构选择对应安装包。已安装 x64 版的 ARM 用户可手动覆盖安装 ARM64 版以切换架构。
- CI 构建和更新元数据验证不等同于 Windows ARM 真机全场景验收。

## 安装与更新

- macOS 使用 DMG 首次安装，后续应用内更新使用已签名、公证的 ZIP。
- Windows 使用对应架构的 EXE 安装包覆盖安装。
- 正式 Release、滚动下载页和 Cloudflare 更新源沿用同一套版本化产物及 SHA512 校验。
