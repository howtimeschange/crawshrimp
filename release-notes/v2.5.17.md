# v2.5.17 · 云端审批与桌面任务稳定性修复

2026-11-18

## 云端审批与生图

- 天猫批量提交在同一事务中回写批次、款式、素材和任务状态，支持超过 98 张批准图片。任务机在下载素材时持续续租，同款原图只下载一次。
- 驳回后重新生成图片时保留原图与新图的关联。启用超过 100 个模板的提示词库也能读取最新发布版本。
- 云端直接生图为每次提交分配稳定标识，回执丢失后重试会返回已有任务。较晚到达的轮询保留已完成结果，暂时断网或保存中断后可以恢复。
- 1XM 代理托管上游密钥时要求配置代理令牌；分块 JSON 超过重写上限后流式透传。

## 桌面任务与素材

- 后端重启后，尚未发出的生图任务可以重试；已发出但缺少回执的任务保留防重保护。停用适配包后，手动运行和定时任务均受该设置约束，重启后继续生效。
- 桌面端在后端就绪后读取端口和对应凭据。响应体传输中断时及时返回错误，避免操作一直等待。
- 迷你巴拉图包按全尺寸 RGBA 像素核验原图，文案缺少颜色时保留待确认状态。Seedance 和百炼在下载完整视频后才替换已有文件。

## 更新与启动

- 正式发布更新 GitHub latest 和滚动下载标签前，会核对当前版本，防止恢复旧构建时覆盖较新版本。
- 开发启动日志隐藏本地 API 令牌。新建令牌或从空文件恢复时，令牌文件仅允许当前用户读写。
