# 抓虾 Desktop v2.4.12

发布日期：2026-08-13

`v2.4.12` 是 `v2.4.11` 之后的补丁发布，聚焦 MOP 搭配素材真实发布、唯品商品在线统计、商品信息表下载上传、上新资料检查，以及任务完成判定和运营通知读回。

版本等级：`PATCH`。本次变更扩展现有 MOP/唯品会运营适配器和多阶段任务运行底座，不新增一级菜单，也不改变桌面端产品架构边界。

## MOP 搭配素材真实发布

- MOP 运营助手新增「搭配素材发布」任务，读取 Excel 中款号、商品 ID、标题和文案，按款号组合在本地 MOP 云盘素材根目录匹配图片文件夹。
- 发布流程会把本地素材处理成 3:4 安全图，关联 1-6 个商品，并按上下装角色生成搭配标签锚点。
- live_publish 模式通过千牛页面上下文走 `preCheck -> createScu` 发布链路；预检模式只校验 Excel、商品关系和本地素材，不上传也不发布。
- 已存在草稿或已发布搭配内容时支持复用，平台拒绝发布时会记录业务失败原因，不把 rejected `preCheck/createScu` 误判为成功。

## 唯品 MOP SOP 工具包

- 唯品会运营助手新增「MOP-唯品商品在线情况统计」，按商品资料接口分页读取本次上线/下线数量，并结合上次商品信息表或手填基数计算环比。
- 新增「MOP-唯品商品信息表下载并上传云盘」，先生成本地商品信息 CSV，再优先通过森马云盘 API 上传到指定目录，并读取目录接口验证最终文件存在。
- 新增「MOP-唯品商品上新资料检查」，读取上新款号+吊牌价表，查询唯品正式资料和 PDC 信息，检查市场价、禁售风险、商品展示图方图和列表图长图。
- 结果表保留原始输入、平台查询结果、上传读回状态、问题款号和具体失败原因，便于运营复核和二次处理。

## 任务完成判定与通知

- 任务完成卡片补强状态归因，区分真实完成、等待外部登录或授权、部分失败、平台业务拒绝和读回不一致。
- 唯品 MOP 上新资料检查的钉钉通知会列出具体问题款号和原因，避免只看到总数而无法定位处理对象。
- 结果 workbook 增强摘要字段和排序，让运营可直接看到本次成功项、失败项、处理建议和下一步动作。

## 多阶段运行底座

- JSRunner 增强阶段共享数据恢复和浏览器会话下载，适配页面跳转、中途重跑和需要登录态的平台文件。
- Crawshrimp Skill 的 `browser_executor.py` 与 `phase_runner.py` 补强直接 CDP 执行、文件选择器上传和翻页安全限制。
- Vipshop auth check 兼容已登录的 nov-admin 商品资料控制台，减少用户已经登录但任务仍判定未登录的误报。

## 验证

- `node --test tests/*.test.js`
- `PYTHONPATH=. .venv/bin/python -m pytest $(git ls-files 'tests/*.py') -v`
