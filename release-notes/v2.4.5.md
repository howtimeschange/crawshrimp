# 抓虾 Desktop v2.4.5

发布日期：2026-08-04

`v2.4.5` 是 `v2.4.4` 之后的补丁发布，聚焦【巴拉】唯品会包装+主图替换脚本在云盘登录、Windows 表格模板和异机安装 OCR 资源上的稳定性。

## 唯品会包装+主图替换

- 森马云盘登录页、未登录状态和登录超时会统一进入 500 秒人工登录等待，避免脚本立刻失败或在登录页反复刷新。
- 执行模式文案调整为「预检（不执行真实上传）」和「找图并且真实上传」，让运营能更清楚地区分预检与真实上传。
- 默认上传明细模板改为 XLSX，CSV 模板继续保留给旧引用，避免 Windows Excel 识别 CSV 内容异常。
- 唯品会适配器内置自己的 Tesseract OCR runtime，并从 `/adapter-assets/vipshop-ops-assistant/vendor/tesseract/...` 读取，不再隐式依赖天猫适配器资源。
- 适配器包导入安装时会随包携带完整 OCR worker、core 和中英文语言包，异机只安装唯品会脚本也能完成详情图 OCR 定位。

## 验证

- `python3 -m unittest tests/test_vipshop_ops_manifest.py`
- `node --test tests/vipshop-ops-assistant-package-main-image-replace.test.js`
- `git diff --check`

GitHub Actions 会在 `main` 与 `v2.4.5` tag 推送后分别运行测试和桌面构建；正式 tag 构建会同步 Cloudflare R2 更新镜像、发布版本化 GitHub Release，并刷新 `desktop-latest`。
