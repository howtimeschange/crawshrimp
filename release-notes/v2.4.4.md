# 抓虾 Desktop v2.4.4

发布日期：2026-08-04

`v2.4.4` 汇总 `v2.4.3` 之后本地领先 GitHub 的 12 个提交：Semir Seedance 视频网关接入、巴拉视频文案/上传模板升级、AI 视频工作流选择流收敛，以及唯品会热卖跟踪报表和包装+主图打标上传工具。

## Seedance 与 AI 生视频

- 支持 Semir Seedance 网关，Ark 兼容 Base URL 会归一化到正确的 `/api/v3` 形态，避免不同环境配置下任务创建路径不一致。
- 本地 AI 视频服务和设置页补齐 Seedance 网关配置识别，兼容 `SEEDANCE_BASE_URL` / `ARK_BASE_URL` 等别名，不把凭据或环境状态写入仓库。
- Seedance CLI 增加交付骑手示例、环境变量说明和 Ark 客户端回归测试，便于在正式桌面流程外做受控验证。

## 巴拉视频工作流与模板

- AI 视频工作流继续收敛找图、AI 改图与生视频选择流，保留素材版本、选择状态和任务可用性，减少运营在步骤切换中的状态丢失。
- 巴拉短视频文案模板从 CSV 升级为 XLSX，长 ID 按文本保存；生成结果拆分「逛逛标题」和「搜推标题」，并保留原始标题与结构化标题元素。
- 批量上传会填充带 `topicId` 的逛逛活动话题，没有 `topicId` 的话题不会进入提交 payload。
- 文案生成默认模型切到已验证配置，并加入标题长度校验、LLM 重试和错误提示，减少生成结果不可用时的人工排查成本。

## 唯品会运营自动化

- 新增唯品会热卖跟踪报表，支持在已登录页面读取商品、广告、会场等五类运营报表，并输出可审计的字段返回状态。
- 报表对缺失数据保持 `未返回`，对无法计算的派生指标保持 `不可算`，避免把接口未返回误展示为 0 或错误 ROI。
- 新增唯品会包装+主图打标上传流程：支持 PDC 预检、包装图云盘默认路径、主图/列表图来源隔离、三档上传范围和提交前安全门。
- 包装微详情会写入商品展示图目标槽位，商详页处理保留 OCR 锚点、balaOne 头图和拼款边界，避免跨商品或跨款误共享。
- 上传读回兼容 Vipshop CDN 地址规范化，减少成功上传后因为 host 重写被误判为失败的情况。
- 任务进度和结果抽屉新增唯品会预检、上传、警告和成功摘要，运营能直接看到缺权限、缺素材、仅主图上传或详情图上传等状态。
