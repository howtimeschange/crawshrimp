# v2.5.11 · 鞋品标签核验与批量任务恢复

发布日期：2026-09-29

## 鞋品标签与选图

- 加强实拍鞋盒标签、电子标签的款号与色号核验，规范化带引号条码并验证校验位，避免将有效条码误判为冲突款号。
- 标准实拍鞋盒标签优先；电子标签裁剪缺少身份信息时回到完整源图核验，保留混款混色拦截。
- 补充同一实物标签的高置信度小字字段，取消电子标签候选的位置截断，保留去重和身份校验。
- 改进浅色灰底素材的几何配对，避免功能卡混入；损坏图片单独隔离，不中断其他素材处理。

## 批量任务恢复

- 短视频上传遇到页面崩溃或超时后有限次恢复，从宿主持有的进度继续；提交前可重启上传，提交结果不明则标记待核实，不重复写入。
- 上新标签下载支持登录恢复，保留已完成结果；单文件失败独立记录并继续，重名文件分配独立文件名。上新适配包更新至 0.3.1。

## 验证范围

- 鞋品既有业务核验覆盖 84 款、142 款色组及 2882 张可解码成品，由全量运行与修复后受影响款复跑组成；仍有真实原素材缺口，不代表全部槽位齐全。
- README 保留 v2.5.11、v2.5.10、v2.5.9 三个版本说明，历史完整说明保留在 release-notes 目录。
- 桌面测试、各平台构建与发布结果以本次 GitHub Actions 记录为准。
