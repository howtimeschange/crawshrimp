# 抓虾 Desktop v2.5.6

发布日期：2026-09-12

## 深绘鞋品图包识别与失败反馈修复

「【鞋品】整理深绘上新图包」在原图下载成功后，可能因模型识别超时或选图分歧而没有生成 tmz、wpz，最终却显示任务完成。本次更新修复识别恢复和任务状态，并补齐有合格原素材时漏出的 yx 功能卡图。

- 小批候选识别时限调整至 120 秒；超过 12 张候选的整页或精细复核使用 240 秒，HTTP 408/504/524 按超时切换备用模型。
- 全量大图达到独立模型票数后仍有必需槽位分歧时，自动进入分页、聚焦候选及逐槽位复核，保持双模型共识与原有姿势硬校验。
- 已发现功能卡候选而 yx 尚未确认时，使用大图单槽位专项复核。只有完整鞋与功能卡同框且达到独立模型共识才生成 yx；单独鞋垫、卡片、鞋盒和局部特写仍被拒绝。
- 全部款式未生成图包时，任务明确显示失败和具体原因；已下载原素材与结果表仍保存到指定或默认输出目录。部分款式成功时继续保留成功图包。
- 保持 5 张 tmz 使用同一主推色，以及各颜色 wpz、yq 和渠道图的既有规则。

## 验证与发布

- 287 项鞋品组包及任务生命周期 unittest、20 项槽位规则 pytest 通过。
- 使用本机正式客户端复现缺图；修复版用同款两色真实原图和已有模型配置验证，39 张正式输出逐张检查通过，包含 5 张 tmz、12 张 wpz、2 张 yx，52 张原素材完整保留。
- 修复涉及客户端内置 Python 统一后端，单独更新 Adapter ZIP 无法生效，需要升级桌面客户端。
- main 与 v2.5.6 tag 分别触发桌面 CI；跨平台构建、macOS 签名/公证、更新源同步和 Release 发布以 Actions 结果为准。
