# 抓虾 Desktop v2.4.7

发布日期：2026-08-05

`v2.4.7` 是 `v2.4.6` 之后的补丁发布，聚焦 SCM 洗唛吊牌批量下载、Bala 千鸟图生视频队列同步，以及短视频批量上传的防串款保护。

## SCM 洗唛吊牌

- 新增「SCM 运营助手」适配器，入口为 SCM 质量协同洗唛批复判定页。
- 支持从文本或 Excel 批量复制款号，自动清理 `款号:`、空格、逗号、顿号和 `.0` 尾缀，并按款号去重查询。
- 下载洗唛文件和吊牌文件时会按款号创建任务目录，并输出「成分汇总」「下载明细」「异常」三张表，方便运营复核中文成分、英文成分和文件下载状态。
- 默认只导出 SCM 判定已完成记录，页面已有的品牌、年份、供应商等筛选条件会保持不变。
- 查询间隔和下载并发改为脚本内稳定默认值，表单只保留款号、导出目录、任务文件夹名和完成状态筛选等常用参数。

## Bala AI 视频

- 千鸟图生视频批量任务补充 `queued`、`pending`、`waiting` 等队列态识别，已经排队、生成中或已提交的任务不会被重复创建 provider run。
- 轮询接口没有及时返回视频地址时，会从当前页面可见任务卡片里读回可用视频链接，避免页面已经生成但接口延迟导致任务被误报失败。
- QN 图生视频脚本增加页面结果兜底、下载衔接和异常读回覆盖。

## Bala 短视频批量上传

- 真实执行时不再因为 Excel 里存在预检失败行而阻塞其它可执行款号；失败行会以发布失败结果保留在输出表中。
- 进入光合和搜推发布器时按款刷新页面，减少上一款表单状态残留。
- 光合和搜推发布接口返回内容 ID 后会检查本次任务已用 ID，发现疑似上一款内容 ID 时停止写入成功，避免串款。
- 未发布光合、只绑定已有内容 ID 的场景会继续使用已有内容 ID 完成宝贝展示视频替换。
