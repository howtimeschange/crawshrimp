# 抓虾 Desktop v2.4.8

发布日期：2026-08-10

`v2.4.8` 是 `v2.4.7` 之后的补丁发布，聚焦短视频 CDP 恢复、Bala AI 视频工作流素材/结果回收、唯品会包装+主图替换进度汇总，以及项目许可证声明。

版本等级：`PATCH`。本次变更主要是已有适配器、视频工作流、任务底座和发布元数据的稳定性补丁，不新增一级菜单或改变产品架构边界。

## 桌面底座与 CDP 恢复

- CDP Bridge 对 `/json`、`/json/new` 和 `/json/close` 的超时、连接重置、HTTP 5xx 与半截 JSON 响应增加有限重试。
- 页面 WebSocket 仍然可用时，DevTools HTTP 管理端点短暂失败不会立刻丢弃当前连接，降低短视频执行中途被环境抖动打断的概率。
- 短视频批量任务在 fatal failure 后会保留已完成、预检失败和中断行的结果，避免异常退出后导出空工作簿。
- 任务运行 API 增加生命周期与部分结果恢复覆盖，确保前端进度和后端输出记录保持一致。

## Bala AI 视频工作流

- 支持清空后的完整素材召回，重新拉取原图、AI 改图和视频素材时不会遗漏已处理素材。
- 保留来源素材选择、分来源人脸模型配置和已选素材状态，减少重复选择和误用素材。
- 迟到的 AI 改图结果会刷新回工作流视图；失败视频任务保留可重跑路径，不再因为清理历史而丢失后续处理入口。
- QN 图生视频脚本增强任务超时、页面结果兜底和下载衔接恢复，降低接口延迟导致的误判失败。

## 唯品会包装+主图替换

- 优化唯品会包装+主图替换脚本的执行进度、步骤汇总和结果读回，帮助运营区分找图、替换、跳过和失败原因。
- 任务进度工具补充结果摘要回归覆盖，避免长任务只显示粗粒度状态。
- 适配器参数面板继续收敛真实执行所需输入，减少运营侧配置噪声。

## 项目许可证

- 项目自有代码许可证声明切换为 Apache-2.0。
- 补充根目录 `LICENSE`、`NOTICE`，并同步应用包元数据中的许可证字段。
- 第三方依赖和 vendored runtime 仍遵守各自原始许可证。

## 验证

- `node --test tests/*.test.js`
- `PYTHONPATH=. .venv/bin/python -m pytest $(git ls-files 'tests/*.py') -v`

GitHub Actions 会在 `main` 与 `v2.4.8` tag 推送后分别运行测试和桌面构建；正式 tag 构建会同步 Cloudflare R2 更新镜像、发布版本化 GitHub Release，并刷新 `desktop-latest`。
