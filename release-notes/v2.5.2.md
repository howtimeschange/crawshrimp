# 抓虾 Desktop v2.5.2

发布日期：2026-08-29

`v2.5.2` 是 `v2.5.1` 之后的补丁发布，发布本地领先的上新运营助手适配包、深绘服饰吊牌/洗唛 AI 识别裁图、深绘鞋品语义共识验收、鞋品标签下载和买家秀目录保留改进。

版本等级：`PATCH`。本次变更不新增桌面端一级产品模块，主要把已验证的运营适配器、深绘服饰/鞋品图包处理、模型路由和验收工具同步到正式桌面版本。

## 上新运营助手适配包

- 新增「上新运营助手」适配包，包含模拍分图审核、审核后上传云盘、静物核表分图、静物核表上传和 PLM 尺码表 PDF 下载五个任务。
- 分图审核支持本地目录和森马云盘路径两种来源，会读取上市计划表、Sheet 映射、上市批次、产品线和年龄段，输出固定结构审核表。
- 审核后上传会重新读取审核表和原始来源，只处理已确认行，保留源款式文件夹的相对目录结构，并对云盘复制结果做递归核验。
- 静物核表流程按 17 位款色号查找摄影源，只有命中精确款色 JPG 的候选文件夹才进入审核和上传，避免把同款不同色或缺图目录误传。
- PLM 尺码表任务会按“大货、订货、试销单、内评、初版”的优先级选择 PDF，并生成可复核的下载结果表。

## 深绘服饰吊牌/洗唛 AI 裁图

- 「整理深绘上新图包」新增 YQ1 吊牌、YQ2 洗唛的 AI 识别与裁图闭环，浏览器适配器会把候选角色、款色号和原始文件名传给后端处理。
- 后端新增服饰标签处理器，支持废图门禁、款号/款色作用域、尺码 110 优先规则、PDF 页渲染、并发视觉识别和分歧复核。
- 现成 YQ 图需要通过角色、款号、手写占位、否定文字和模型一致性校验后才会短路缺失项；证据不足时保持 fail-closed。
- PDF 或图片候选会按模型返回的坐标本地裁切到 800x800 白底画布，并通过 OCR/尺寸/边界校验降低错误吊牌、洗唛和废图混入风险。
- 新增真实样本验证产物和单元测试，覆盖 YQ 识别边界、并发审查、PDF 单元合并、尺码选择、裁图验收和深绘打包集成。

## 深绘鞋品语义共识与标签下载

- 鞋品图包识别改为结构化候选事实与多模型共识，只有不同模型独立同意并通过槽位硬门禁的素材才会自动锁定。
- 鞋品槽位规则加强对主图、角度图、鞋盒、吊牌、单鞋/双鞋、后跟/侧后和特征卡的语义要求，减少姿势相似但内容错误的误判。
- 串行 rerun 与 validator 会把语义属性、模型投票、鞋盒命名和槽位问题写入报告，便于真实款号逐款验收。
- 鞋品标签瓦片下载支持更稳的批量下载、PDF/截图处理和 API 返回结构，减少吊牌、鞋盒、电子标签等素材在下载阶段丢失。
- 深绘鞋品打包测试扩展到共识投票、全局页匹配、单 Sheet 输入、OCR 辅助验证、失败隔离和真实验收报告。

## 买家秀、模型路由与 OCR 支撑

- 买家秀云盘生成任务支持保留模型图片来源的子文件夹结构，输出包能区分不同模型或款式目录，方便后续复核与交付。
- LLM 设置补齐 GLM 官方模型路由和相关前端配置，深绘识别、服饰标签和视频文案等入口可以复用统一的模型能力判断。
- 后端新增 OCR 服务支撑，用于标签裁图、鞋品报告和图片/PDF 复核场景，测试覆盖 Tesseract.js 可用性、不可用降级和错误边界。
- AI 视频生成安全接口测试补强，保证模型配置和安全边界在新增图像识别能力后仍保持可控。
