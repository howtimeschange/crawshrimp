# 抓虾 Desktop v2.4.16

发布日期：2026-08-19

`v2.4.16` 是 `v2.4.15` 之后的补丁发布，聚焦 TEMU 洗唛制作、AI 视频文案生成和深绘上新图包交付三条运营链路：增强 SCM 明细 PDF 洗唛附件识别，默认使用 Gemini 3.5 Flash 生成视频文案，并对深绘上新/鞋品图包做高质量压缩与结果表回写。

版本等级：`PATCH`。本次变更修复并增强现有适配器、LLM 网关和后端导出逻辑，不新增一级菜单，也不改变桌面端产品架构边界。

## TEMU 洗唛 SCM 明细 PDF 识别

- SCM 明细附件兜底从可见 DOM 图片扩展到 Vue 组件数据，能读取组件里的 `myListData` 洗唛附件列表。
- 明细附件统一归一为可下载记录，支持洗唛、水洗和 wash 分组，并保留 `scm_detail_component_attachment` 来源。
- PDF 洗唛会保留原文件名、类型、大小和 URL；下载时继续使用 `%PDF-` 签名校验，避免把吊牌或异常文件误送入 AI/OCR 识别。
- 结果证据继续保留 `scmWashFileSource` 和 `scmWashFileName`，便于复核为何使用 SCM 明细附件。

## Gemini 视频文案默认模型

- 生意管家视频文案默认模型切换为 `gemini-3.5-flash`，全局配置、后端默认值、适配器 manifest 和前端设置保持一致。
- Gemini 系列通过 OpenAI 兼容接口调用时，会先下载远程商品图并转成 base64 data URL；非 Gemini 模型继续使用远程图片 URL。
- 通用多模态 JSON 调用也支持 Gemini 远程图转 base64，保证鞋品姿势识别、视频文案等多图任务走同一套图片传输规则。
- 短视频批量上传标题长度校验改为按可见字符统计，降低 emoji、组合字符带来的字数误判。

## 深绘上新与鞋品图包压缩

- 深绘「整理上新图包」和「鞋品上新图包」新增「压缩结果」输出列，后端会把压缩原因、尝试结果和压缩前后体积写回结果表。
- 单图超过阈值时会优先对该图片做高质量压缩；单款总图包超过阈值时，会按大图优先压缩并回写到对应行。
- 压缩逻辑保持原尺寸和原文件名，移动到用户选择的导出目录后仍会刷新结果 Excel 中的最终本地路径。
- 深绘款号 ZIP 产出流程会在压缩后再打包，避免直接上传深绘时带入过大的原始图片。
