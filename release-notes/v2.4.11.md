# 抓虾 Desktop v2.4.11

发布日期：2026-08-12

`v2.4.11` 是 `v2.4.10` 之后的补丁发布，聚焦 LZH 洗唛洗护符号校准、唯品会包装+主图替换 OCR 加载稳定性、详情图下载与上传兜底，以及 JSRunner 下载链路恢复能力。

版本等级：`PATCH`。本次变更修复现有 TEMU/LZH 洗唛和唯品会运营适配器的稳定性问题，不新增一级菜单，也不改变桌面端产品架构边界。

## LZH 洗护符号校准

- LZH 洗唛场景沿用 TEMU 洗护符号校准表，并补齐人工复核后的默认值，避免平摊晾干、低温熨烫、不可熨烫等符号在兜底时被错误覆盖。
- 洗唛创建脚本在 SCM 判定文本、AI 附件识别和固定兜底之间保留逐项合并逻辑，只对缺失字段使用默认值。
- JSRunner 补强阶段共享状态恢复，让洗唛流程在页面跳转或中途重跑后仍能保留必要上下文。

## 唯品会 OCR 加载稳定性

- 唯品会包装+主图替换适配器升级为 `0.2.2`，并同步测试期望，确保发布包能明确区分旧版资源和本次 OCR 修复。
- OCR Worker 加载增加多路径兜底，优先使用适配器本地资源，并在资源地址、worker 初始化或语言包加载失败时给出可追踪的失败原因。
- Tesseract 初始化流程补充预检和错误归因，减少页面只显示通用 `Failed to fetch` 时难以判断是 worker、core wasm、语言包还是浏览器策略导致的问题。

## 详情图下载与上传兜底

- 唯品会详情图处理支持在图片下载失败时继续保留页面证据和失败明细，不再让单张图片异常拖垮整批款号。
- 详情图上传链路增强重试、结果回读和失败汇总，运营可在结果表里区分找图失败、下载失败、上传失败和平台回读不一致。
- JSRunner 的 `download_urls` 增加更稳的浏览器会话下载恢复路径，适合处理需要当前登录态或平台资源权限的图片下载。

## 验证

- `npm --prefix app test`
- `node --test tests/*.test.js`
- `PYTHONPATH=. .venv/bin/python -m pytest $(git ls-files 'tests/*.py') -v`

GitHub Actions 会在 `main` 与 `v2.4.11` tag 推送后分别运行测试和桌面构建；正式 tag 构建会同步 Cloudflare R2 更新镜像、发布版本化 GitHub Release，并刷新 `desktop-latest`。
