# 抓虾 Desktop v2.4.15

发布日期：2026-08-18

`v2.4.15` 是 `v2.4.14` 之后的补丁发布，聚焦 TEMU 洗唛、深绘素材下载和生意管家短视频批量上传三条已上线运营链路的可靠性：补齐 SCM 明细附件兜底，压缩深绘下载结果，并在短视频批量上传中断时保留已完成明细和失败原因。

版本等级：`PATCH`。本次变更修复并增强现有适配器、JSRunner 和后端导出逻辑，不新增一级菜单，也不改变桌面端产品架构边界。

## TEMU 洗唛 SCM 明细附件兜底

- TEMU 洗唛制作在列表数据没有返回洗唛附件时，会继续读取 SCM 明细页附件区，从明细中的吊牌、洗唛或平铺资料中寻找可识别的洗唛来源。
- 保留列表优先、明细兜底的处理顺序；只有列表无可用洗唛时才使用明细附件，避免覆盖原本更直接的 SCM 列表证据。
- 明细附件命中后会写入 `scmWashFileSource`、`scmWashFileName` 和识别来源，便于运营从结果表追溯洗唛图/PDF来自哪里。
- 适配器测试覆盖明细附件兜底、来源字段保留和缺失附件时的失败原因，避免把“无列表附件”误判为全量缺资料。

## 深绘素材下载结果压缩

- 深绘上新助手的吊牌、洗唛和平铺图下载完成后，会在导出目录中生成压缩包，方便运营把整批素材和结果明细直接交付或转存。
- 压缩逻辑复用后端收尾流程，和唯一目录命名、指定导出目录移动、临时文件清理一起执行，减少手动整理和漏文件风险。
- 回归测试覆盖压缩文件生成、压缩包内容和原有下载结果明细，确保压缩交付不影响逐行复核。

## 生意管家短视频批量上传中断恢复

- 短视频批量上传在页面文件注入、上传控件或浏览器状态异常时，会读取最后稳定的 JSRunner 共享状态，导出已处理行而不是空结果表。
- 结果表继续区分已完成、预检失败和发布失败；中断行会标注具体失败原因，便于运营确认哪些款号需要重跑。
- JSRunner 增加阶段共享状态快照，仅用于这类需要在 fatal failure 后恢复部分结果的任务，不改变普通浏览器自动化的运行锁和失败语义。
- 适配器脚本在提交前后保留当前行状态、运行 ID 和结果记录，防止上传中断后丢失已经成功或已明确失败的款号。
