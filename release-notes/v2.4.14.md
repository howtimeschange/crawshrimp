# 抓虾 Desktop v2.4.14

发布日期：2026-08-17

`v2.4.14` 是 `v2.4.13` 之后的补丁发布，聚焦深绘上新助手的批量素材下载：从森马云盘按款号定位吊牌、洗唛和平铺图，优先复用已登录 Chrome/CDP 的云盘会话，并把下载结果按款号整理成可直接交付给运营复核的本地文件夹和明细表。

版本等级：`PATCH`。本次变更新增并增强深绘上新适配器脚本，不新增一级菜单，也不改变桌面端产品架构边界。

## 深绘批量素材下载

- 深绘上新助手新增「批量下载吊牌/洗唛/平铺图」任务，可输入多款款号或款色编码，从默认平拍路径和可选模拍路径中批量查找素材。
- 吊牌和洗唛优先命中 `yq1` / `yq2` 命名文件；缺失时按吊牌、合格证、洗唛、水洗等文件名规则回退，并支持纯款号 PDF 兜底识别洗唛。
- 平铺图优先从模拍原图路径查找；如果款号在模拍路径命中，导出的平铺图文件名会追加「有模拍」，便于后续区分有模拍款。
- 平铺图按款色分组，每个款色只取一张代表图，并过滤 `-1` 等背面图，优先保留类似 `208426108223-00422` 的款色编码图片。

## 下载与结果整理

- 新脚本沿用抓虾 JSRunner 的 `download_urls` 能力，支持批量下载进度、下载并发参数和浏览器会话下载，适配需要云盘登录态的素材文件。
- 下载完成后后端会按款号创建本地目录，把吊牌、洗唛、平铺图和结果明细统一整理到导出文件夹；指定导出目录时会移动到用户选择位置。
- 结果 Excel 保留输入款号、素材类型、素材来源、云盘路径、匹配策略、模拍命中、下载结果、本地文件和备注，方便运营逐行检查缺图或回退原因。

## 深绘适配器集成

- `manifest.yaml` 新增任务参数、默认森马云盘路径、模拍路径和输出列定义，保持与「整理深绘上新图包」任务一致的手动入口体验。
- 后端新增深绘吊牌/洗唛/平铺图导出收尾逻辑，复用安全文件名、唯一目录、指定导出目录移动和孤儿运行文件清理能力。
- 适配器测试覆盖 `yq1/yq2` 优先级、纯款号 PDF 洗唛兜底、模拍平铺图优先、文件名「有模拍」追加、款色单图选择和背面图过滤。

## 验证

- `npm --prefix app test`
- `node --test tests/*.test.js`
- `PYTHONPATH=. venv/bin/python -m pytest $(git ls-files 'tests/*.py') -v`
- `npm --prefix app run vite:build`
- `git diff --check`

GitHub Actions 会在 `main` 与 `v2.4.14` tag 推送后分别运行测试和桌面构建；正式 tag 构建会同步 Cloudflare R2 更新镜像、发布版本化 GitHub Release，并刷新 `desktop-latest`。
