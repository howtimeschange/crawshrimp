# 抓虾 Desktop v2.3.0

发布日期：2026-07-25

`v2.3.0` 是一次功能级发布，包含 `v2.2.2` 之后全部尚未打正式 tag 的提交。重点补齐电商短视频文案与发布、跨境/深绘图包整理、天猫按风格参考图以及桌面主题和文本大模型配置。

## 短视频文案与批量发布

- 巴拉 AI 视频助手新增「AI生成视频标题和文案」，复用已登录的千牛商品页读取商品标题、款号和主图，通过设置中的文本大模型生成三组候选视频标题与约 30 秒文案，并导出短视频批量上传 Excel。
- 新增「短视频批量上传」，按款号匹配本地 MP4，可依次发布光合逛逛内容、创建搜推素材并只替换商品的「宝贝展示」视频。
- 发布链路支持计划检查与真实执行，保留光合内容 ID、三个入口的接口回执和商品刷新读回，便于定位单款失败并审计实际提交结果。
- 视频素材工作区进一步稳定文件恢复、缩略图显示和选择状态；下载图片默认按 10MB 阈值处理，减少后续模型与上传链路因超大图片失败。

## SHEIN 与鞋品深绘图包

- 森马云盘图片工具新增「SHEIN 图包下载」，在指定云盘范围内按款号定位同名文件夹，递归下载完整目录并合并输出 ZIP 与结果记录。
- 深绘上新助手新增鞋品上传包整理：按款号和货号识别平拍、模拍、吊牌、洗唛等素材，结合鞋品品类映射生成标准上传包。
- 鞋品流程保留原始图片，不再为了输出包统一缩放；主图、姿势和多模拍选择规则加强，避免同款素材不足或候选歧义时静默选错。
- 参数面板收敛为实际业务必需输入，并增加分阶段进度与更清晰的识别结果，长时间 Qwen 识别时也能看到当前处理位置。

## 天猫 AI 测图与文本大模型

- 天猫 AI 测图支持为每个款式维护独立的自定义参考图池，避免不同风格、不同商品之间串用参考素材。
- 提示词选择与行内操作简化，抽屉审批、任务进度和全链路状态回传更加稳定。
- 新增统一文本大模型网关与设置项，支持默认模型、供应商地址和连通性测试；凭据继续只在本地设置与运行时使用。
- 视频文案任务通过同一模型配置调用，不在脚本中固化密钥或底层传输细节。

## 桌面主题与交互

- 桌面端新增浅色、深色与跟随系统三种外观模式，并在主要工作台、设置、任务中心、数据页、脚本列表和弹窗中统一主题变量。
- 主题选择本地持久化，系统主题变化时可自动同步；新增视觉契约测试防止主要界面重新出现不可读的硬编码颜色。
- 任务进度组件补充阶段、计数和消息归一化，长任务在不同脚本页面中保持一致的可读反馈。

## 验证

- `npm --prefix app test`
- `node --test tests/*.test.js`
- `PYTHONPATH=. ./venv/bin/python3 -m pytest tests -q`
- `npm --prefix app run vite:build`
- `git diff --check`

GitHub Actions 会在 `main` 与 `v2.3.0` tag 推送后分别执行完整测试与桌面构建；正式 tag 会先同步 Cloudflare R2 更新镜像，再发布版本化 GitHub Release 并刷新 `desktop-latest`。
