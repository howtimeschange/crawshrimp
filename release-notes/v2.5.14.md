# v2.5.14 · 森马与迷你巴拉上新素材整理

发布日期：2026-11-09

## 森马上新助手

- 支持 PLM 尺码表导出、指定批次云盘图包整理、SCM 洗唛吊牌及三方检测报告批量下载。
- 图包按明确的批次和款色目录采集；SCM 保留当前页面筛选，读取全部分页和附件。
- 原件、分款 ZIP 与 Excel / JSON 明细保留来源、哈希及异常，缺件或失败如实记录。

## 迷你巴拉上新助手

- 支持 PLM 尺码表导出、按文案整理图片，以及跨相关挂载点发现并核验检测报告正文款号。
- 三款已核准样例通过选图清单与原图哈希独立生成 274 张图片，另保留 3 份报告 PDF；示例图片仅用于验收，不用于补图。
- 保留图片多用途、平台图加工、PDF 截图和已核准电子洗唛数据，输出缺项、来源与规则冲突。
- 三款样例已完成复跑验收；其他款沿用文案与 AI 选图流程，需另行核验。

## 名称与发布

- 两款现有助手分别更名为“巴拉上新运营助手”和“巴拉上新助手”。
- 新适配器涉及后端集成，需使用包含本次改动的桌面版本。
- macOS 构建迁移至受支持的 runner；公证票据下载与验证遇到网络中断时有限重试。
- README 保留 v2.5.14、v2.5.13、v2.5.12 最近三个版本说明，历史说明继续保存在 release-notes 目录。

## 验证

- 本地桌面端 527 项、适配器 JavaScript 1,381 项、相关 Python 43 项测试通过，前端构建通过。
- 森马素材包保留缺件与页面筛选范围；三款迷你巴拉样例的验收结论不外推到其他款。
