# 抓虾 Desktop v2.4.6

发布日期：2026-08-05

`v2.4.6` 是 `v2.4.5` 之后的补丁发布，聚焦 Bala AI 视频提交超时恢复、唯品会 OCR runtime 完整性，以及桌面更新镜像的 R2 大文件上传稳定性。

## Bala AI 视频

- 恢复「千鸟图生视频」提交链路对长耗时任务创建接口的等待和重试，避免真实提交在接口响应慢时过早超时。
- 补充 QN 图生视频脚本回归覆盖，固定提交恢复路径和错误提示边界。

## 唯品会包装+主图替换

- 唯品会适配器继续只从 `/adapter-assets/vipshop-ops-assistant/vendor/tesseract/...` 读取自己的 OCR runtime，不再隐式依赖天猫适配器资源。
- OCR runtime 恢复为完整 Tesseract 包，随适配器携带 worker、core 以及中英文语言包，降低不同电脑上因 core/lang 动态解析差异导致 OCR 加载失败的风险。

## 桌面更新镜像

- GitHub Actions 的 Cloudflare R2 上传从 `wrangler r2 object put` 切到 R2 S3 endpoint 的 `aws s3 cp`，让正式 tag 发布的大 ZIP 可以走 multipart 上传。
- R2 元数据回读校验也改用 S3 endpoint 下载 `latest-mac.yml` 和 `latest.yml` 后比对，保留发布后的 updater feed 校验。

## 验证

- `node --test tests/bala-ai-video-assistant-qn-img2video.test.js`
- `node --test tests/vipshop-ops-assistant-package-main-image-replace.test.js`
- `node --test tests/tmall-ops-assistant-packaging-upload.test.js`
- `python3 -m unittest tests/test_vipshop_ops_manifest.py tests/test_tmall_ops_packaging.py tests/test_ocr_service.py -v`
- `git diff --check`

GitHub Actions 会在 `main` 与 `v2.4.6` tag 推送后分别运行测试和桌面构建；正式 tag 构建会同步 Cloudflare R2 更新镜像、发布版本化 GitHub Release，并刷新 `desktop-latest`。
