# v2.5.9 · 鞋品标签恢复与功能卡识别加强

## 鞋品任务与标签核验

- 下载前检查专属模型品类表，缺失、无效或冲突时提前提示。
- 改进颜色字段识别，兼容“额色”“色：”等 OCR 结果，通过标签位置和颜色文字核对完整色号。
- 识别不完整时局部 OCR 重试并尝试其他鞋盒候选；区分无法确认与明确不匹配，保留已完成款色及待复核原图。
- 电子标签整版按区域拆分读取，仅通过实拍可读款色或相同有效 EAN 条码关联；不以文件名独立确认身份，不使用电子稿坐标框选实拍。

## YX 功能卡

- 内置 YX v3 分类头，补入单张浅色小卡片及相近无卡鞋图，保持0.5阈值和其他图位模型不变。
- 修复有功能卡素材却未输出 YX 的情况，保留模型版本、哈希和前三候选用于复核。
- 19款、31款色、708张候选的正式脚本 YX 回归：23组有卡选对，8组无卡未误选。
- 全量回归包含训练样本；逐款留出开发验证30/31，不代表未见新款100%准确。

## 打包与验证

- 最新权重、模型清单和电子标签模块直接随项目打包，构建检查缺失模块及模型 SHA256。
- 同六款真实素材重新识别导出8张 YX，392张结果图片可读取，其他图位选择不变。
- 19款验收范围为 YX；其中历史款204426140052两个颜色的附带鞋盒OCR仍待复核，不计作完整图包验收。
