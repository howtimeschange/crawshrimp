# 抓虾 Desktop v2.4.13

发布日期：2026-08-14

`v2.4.13` 是 `v2.4.12` 之后的补丁发布，聚焦 AI 视频工作流里的生意管家生视频链路：新版批量生成参数、任务结果绑定、异步刷新、下载回显、本地文件清理，以及新增视频任务弹窗的批量选择和模型配置引导。

版本等级：`PATCH`。本次变更修复并增强现有 AI 视频工作流和生意管家视频适配器，不新增一级菜单，也不改变桌面端产品架构边界。

## 生意管家批量生成链路

- `qn-img2video` 适配器兼容新版批量生成接口，按页面返回的任务标识跟踪本次提交，不再把旧页面结果误认为当前任务完成。
- 生成档位作为明确枚举参数进入 AI 视频工作流和适配器 manifest，可在任务创建、审核抽屉和任务执行参数之间保持一致。
- 批量生成会汇总平台返回的单条失败、整批失败和成功明细，导出与 UI 状态能区分部分失败、等待中和真实完成。
- 提交流程保留当前任务的票据和运行 ID，刷新结果时优先匹配本轮运行，避免正在进行中的任务被上一轮下载记录覆盖。

## 视频结果刷新与本地回显

- 已下载视频优先以本地文件作为播放源，远端 URL 只作为兜底；本地文件变化后会刷新媒体 key，避免播放器继续缓存旧视频。
- 清理视频结果时同步清理持久化记录、预览状态和旧本地路径，界面不会在删除后继续展示上一轮结果。
- 应用启动和页面恢复时，对还在进行中的视频任务保留加载态，并继续刷新真实任务状态，不把历史完成记录自动套到当前任务上。

## 本地文件删除桥

- Electron preload、开发桥和主进程删除入口统一把路径转为可结构化克隆的纯字符串数组，修复 `An object could not be cloned`。
- 后端 `/files/delete` 放开“必须位于 Crawshrimp 数据目录内”的旧限制，允许删除已登记的任务输出文件，例如 `~/Downloads/AI视频/...mp4`。
- 删除仍保留安全边界：未登记文件、用户 Home、根目录和目录目标都会拒绝，删除成功后同步移除任务输出引用。

## 新增视频任务体验

- 新增视频任务弹窗增加“全选当前筛选 / 取消全选”，仅作用于当前款号、来源类型和状态筛选下可选择的素材。
- 批量选择会遵守不同 API 模型的图片数量上限，并在达到上限时给出当前模型的选择提示。
- API 模型未配置提示移动到模型选择区域下方，显示当前凭据状态、模型使用说明，并提供直达「AI 能力配置」的入口。

## 启动与错误提示

- 桌面端启动期间的后端探测和重试更稳，重新启动时的偶发连接报错会被归因到后端启动状态，不再让用户误以为功能失败。
- 侧边栏和脚本入口保留启动恢复提示，切换页面后可继续使用已恢复的后端连接。
