# 抓虾 Desktop v2.5.0

发布日期：2026-08-22

`v2.5.0` 是 `v2.4.16` 之后的功能级发布，新增 AI 买家秀工作流，并集中发布买家秀生成、深绘鞋品图包、AI 视频素材选择、Vipshop 主图替换和多模型配置等本地已验证改进。

版本等级：`MINOR`。本次变更新增桌面端独立工作流入口，并配套后端服务、任务状态、结果历史和森马云盘适配器能力；同时包含多条现有运营链路的补丁增强。

## AI 买家秀工作流

- 桌面端新增「AI 买家秀工作流」入口，按步骤组织买家秀 Excel、输出目录、模型、Prompt、续跑目录和任务状态。
- 后端新增 `buyer_show_service`，支持从买家秀需求 Excel 读取行级数据，自动下载森马云盘人物模拍图，并按款色号匹配平铺参考图。
- 森马云盘适配器新增 AI 买家秀任务与模板，覆盖原图下载、匹配、生成、续跑、结果打包和结果 Excel 输出。
- 买家秀生成支持 GPT Image/1XM 系列模型、默认换装 Prompt 与单批自定义 Prompt，结果记录模型任务 ID、本地文件、打包目录和失败原因。
- 结果历史独立成队列，桌面端可以查看历史运行、打开目录、下载结果和清理记录，图片生成任务不再混入普通工作台历史。

## 深绘鞋品上新图包

- 鞋品上新图包更新主图、角度图和海报模板素材，并同步深绘脚本 manifest 中的任务参数与说明。
- `shenhui_shoe_packaging` 强化白底单鞋、鞋型姿势、主图和角度图选择逻辑，降低双鞋、姿势错误和模板不匹配带来的返工。
- 批量处理支持更清晰的行级失败隔离和进度回写，缺少单款素材时会记录具体原因并继续处理其它款。
- 鞋品策略 UI 更紧凑，进度展示与模板姿势规则保持一致，便于运营在桌面端确认当前批次状态。

## AI 视频与多模型配置

- AI 视频素材流程保留用户已选素材，清理 stale restore 状态，并改进素材去重，避免切换步骤或刷新时丢失选择。
- Bala 视频任务新增 AI Prompt Writer，配合模型配置生成更稳定的短视频文案与素材提示词。
- LLM 设置拆分 provider 配置，补齐 DeepSeek 官方与 DeepSeek 网关模型路由，减少不同入口之间的默认模型不一致。
- AI 图片任务隔离和素材恢复测试覆盖更多队列状态，避免买家秀、AI 生图、AI 视频之间的历史任务串线。

## Vipshop、桌面与脚本体验

- Vipshop 主图替换补强 PDC 图片持久化校验，已标记替换结果会通过页面读回确认，减少“页面看似替换但后台未保存”的风险。
- Vipshop ops adapter 版本同步提升，manifest 与脚本测试覆盖新的替换校验行为。
- 桌面端更新应用图标，并修正 cloud approval shell probing 对本地桌面启动的干扰。
- 脚本列表新增搜索能力，收藏、搜索和任务中心导航测试同步覆盖；manifest schema 同步支持 `model_chain` 参数类型。
