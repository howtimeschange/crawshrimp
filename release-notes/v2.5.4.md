# 抓虾 Desktop v2.5.4

发布日期：2026-09-10

版本等级：`PATCH`。本次为现有执行、恢复和媒体能力的维护修复，不新增独立产品模块或改变核心架构。

`v2.5.4` 是 `v2.5.3` 之后的补丁发布，集中修复任务异常恢复、批量发布回执、生图持久化与视频历史清理，并改善大批素材和 PDF 预览时的桌面响应。

- 任务执行统一限制非幂等阶段重放；发布回执未知时保留待核实状态，停止或异常后继续导出已完成行。只读 PLM 查询保留短暂 CDP 断连重试。
- 生图提交持久化原始幂等键，区分提交结果未知与明确失败；后端重启后恢复已提交任务的查询，阻止旧响应覆盖终态。
- 云端任务在逐款执行边界检查取消和租约状态，避免取消或失去租约后继续发起后续款号的写入。
- 视频任务 ID 使用完整 UUID，避免短随机后缀碰撞；视频重试按执行批次隔离，修复历史结果与工作区清理，防止旧轮询、旧扫描或旧预览响应写回新状态。
- 工作区扫描、哈希、清理和 PDF 预览使用 Worker；缩略图异步解码并限制并发，后端短暂健康检查失败时保留可恢复进程。
- 对齐产品架构、开发指南和 Adapter SDK/schema 与当前运行时，补充深绘任务回归验证。

## 构建与验证

本地验证：桌面端 Node 484 项、Adapter Node 1,301 项、Python 1,269 项及 49 个子测试通过；Amazon 标签样本缺失的 1 项跳过。Vite 生产构建与 `git diff --check` 通过。新增固定 UUID 短前缀碰撞测试，覆盖新建任务与重试记录。

`main` 与 `v2.5.4` tag 推送分别触发 GitHub Actions 测试和桌面构建。正式 tag 流程执行 macOS 签名/公证、更新资产校验、Cloudflare R2 同步、版本化 Release 与 `desktop-latest` 发布；实际结果以对应 Actions 记录为准。

本次发布不等同于 Windows/macOS 三平台应用内更新全流程的人工验收，尚未执行的项目在桌面更新发布验收清单中保留 `PENDING`。
