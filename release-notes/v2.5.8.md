# v2.5.8 · 短视频批量上传刷新修复

发布日期：2026-09-20

## 短视频批量上传

修复批量切换视频时，发布器弹出“重新加载此网站”确认框后任务超时中断的问题。

- 页面脚本先返回并保留当前进度，再由执行器导航或刷新发布器。
- 在同一浏览器控制连接中处理本次导航触发的离开确认，确认新的主文档加载完成后再继续上传。
- 其他类型弹窗、导航失败或新页面加载超时会停止后续操作，不会在旧页面继续上传。
- 保留已完成结果；发布回执未知时不自动重复提交，避免重复发布。
