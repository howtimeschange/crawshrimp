# 抓虾 Desktop v2.4.10

发布日期：2026-08-12

`v2.4.10` 是 `v2.4.9` 之后的补丁发布，聚焦 TEMU AI 洗唛洗护符号校准、洗唛附件 AI 识别结果落库，以及平台页面访问本地适配器资源的私有网络预检兼容。

版本等级：`PATCH`。本次变更修复现有 TEMU 洗唛制作和本地适配器资源服务的稳定性问题，不新增一级菜单，也不改变桌面端产品架构边界。

## TEMU 洗护符号校准

- 建立 TEMU 五类洗护符号完整枚举表，覆盖洗涤、漂白、干燥、熨烫和专业护理的 TEMU 值、标准 ID、英文标签和中文含义。
- 修正干燥/熨烫关键映射：`drying=4` 为悬挂晾干，`drying=8` 为平摊晾干，`ironing=3` 为低温熨烫，`ironing=4` 为不可熨烫。
- SCM 判定备注或洗唛说明只缺少某一类时，只对缺失项使用默认兜底，保留已经识别正确的其他符号，避免整组回退导致平摊晾干、不可熨烫等字段被覆盖。
- 结果导出新增洗护符号标准 ID，便于运营复核 TEMU 页面值、SCM 说明和保存 payload 是否一致。

## 洗唛附件 AI 识别

- 多模态识别提示词加入 TEMU 枚举校准表，要求模型直接返回 `careSymbols` 数字值，并明确看不清的字段必须留空。
- 识别结果会缓存并复用同款洗唛附件的 `careSymbols`，后续 SKU 可直接使用已校准的符号值，不再只依赖文本规则二次猜测。
- AI 只识别出部分字段时，会用最新 SCM 文本映射补齐缺失项；两者都缺失的字段再回到固定 SOP 默认值。
- 样例回归覆盖了平摊晾干、不可熨烫、低温熨烫、AI 识别优先级和部分识别补齐路径。

## 本地适配器资源预检

- `/adapter-assets/` 资源接口补充私有网络访问预检响应，允许平台页面在浏览器 Private Network Access 规则下加载本地 OCR、Tesseract 等适配器静态资源。
- 预检响应明确返回 `Access-Control-Allow-Private-Network: true`、允许 `GET, OPTIONS`，并保持资源本身的跨源和长期缓存策略。
- 全局 API token 校验会放行适配器资源的 `OPTIONS` 预检，但不放宽实际 API 的认证边界。

## 其他执行稳定性

- 款号展开 SKU 时会在展开后应用 `max_downloads` 限量，避免一个款号展开出多条 SKU 后超出本次下载上限。
- 新增 TEMU 洗护符号映射文档，记录 2026-08-12 人工校准来源、关键纠偏和完整枚举表。
